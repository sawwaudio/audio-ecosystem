# saww audio ecosystem — FREE / PRO の区分と課金の設計（v0.43）

**状態：提案（未承認）。課金は無効。テスト公開中は、すべての機能を無料で使える。**
料金はすべて米ドル（USD）建て。正式な承認の前に、実際の請求は始めない。

## 1. プラン

| | FREE — create & share. | PRO — perform & produce. |
|---|---|---|
| 料金 | $0 / forever | $9.99 USD / month、$99 USD / year（提案価格） |
| 目的 | 誰でも自然音で短い動画を作り、共有できる | ライブ・作曲・録音・書き出しまでできる、本格的な制作環境 |
| 最重要の指標 | 作った動画の共有率 | FREE からの転換率、有料の継続率 |
| アカウント | 不要 | 必要（決済と権利の管理のため） |

機能の区分は `data/product_tiers.json` にあり、アプリの「PLANS — FREE / PRO」の表はこのファイルから作る。

| 機能 | FREE | PRO |
|---|---|---|
| 写真をタップして実録音を再生・重ねる | ✓ | ✓ |
| 実録音ライブラリ（絞り込み・地域・試聴・権利情報） | ✓ | ✓ |
| 自分の音を読み込む（端末の外へ送らない） | ✓ | ✓ |
| リール作成（9:16・1080×1920・15〜60秒・テンプレート8種） | ✓ | ✓ |
| クレジットの自動作成・コピー・共有 | ✓ | ✓ |
| 自律演奏 | ✓ | ✓ |
| DJ ミキサー（チャンネル EQ・フィルター・マスター EQ） | — | ✓ |
| BEAT FX 10種・チャンネル FX | — | ✓ |
| サンプラー（切り取り・8パッド） | — | ✓ |
| マルチトラック（重ね録り・ミュート・ソロ・送り先） | — | ✓ |
| 高音質の書き出し（WAV・AIFF 24-bit） | — | ✓ |
| MIDI コントローラー | — | 予定 |
| プロジェクトの保存 | — | 予定 |

画面では、PRO の機能の見出しに「PRO」の印を付ける（ミキサー・サンプラー・トラック・LIVE CAPTURE）。
いまは印だけで、機能は制限しない（`window.sawwEntitlement.enforce === false`）。

## 1b. 無料版で鳴らせる楽器（v0.55、2026-11-07 オーナー要望「無料版では出せる楽器を限る」）
- 無料版の楽器（実録音）は6種：ディジュリドゥ（持続音）・自然の低音・パイプオルガンのペダル・ハープ・カリンバ・フレームドラム。
  - ディジュリドゥは「すごい良い」とのオーナー評価があり、入口として無料に残す。
  - 低音・旋律・打楽器から最低1つずつ入れている。
- 合成音（シンセ）は無料版でもすべて使える。
- それ以外の実録音の楽器は PRO。伝統楽器（ムビラ・バラフォン・ダン・チャン・弓で弾くプサルテリー・ハンドベル・ディジュリドゥのフレーズ、今後の口琴など）もここに入る。
- 一覧は data/product_tiers.json の instruments.free だけで決まる。入れ替えはこの1行を変える。新しく足した楽器は、一覧に入れない限り PRO。
- いまは課金が無効なので、全部鳴る（plan 'beta'）。
  - 楽器の欄では PRO の楽器に印を付け、正式公開後に PRO になることが分かるようにしている。
  - プランの欄の「無料版の見え方を試す」を入れると、制限を確かめられる（端末に記憶する）。
  - 制限中、PRO の楽器はつまみが止まり、鳴っている音も消える。自律演奏・プリセット・MIDI でも鳴らない。
- 正式な課金を始める時は、3章のとおり署名付きの権利情報で plan を決める。いまの判定（window.__instrAllowed）はブラウザの中だけなので、詳しい人なら外せる。

## 1c. 無料版で鳴らせる生き物の声（v0.63、2026-11-08 オーナー要望「無料版は生き物の声を出せすぎ。各分類3〜4種に絞り、残りは PRO」）
- 分類ごとに4種、計20種。97録音のうち、残りの77録音は PRO。
  - 鳥：ウグイス（横浜）・ウタツグミ・ミソサザイ・ナイチンゲール（ロシア）。初期設定（v0.58）で鳴る4種と同じ。
  - 虫：アブラゼミ（cicada）・ヒグラシ・虫の合唱（千葉・柏）・夜のコオロギ（米国ワシントン州）。
  - 両生類：ヨーロッパヒキガエル・水田のカエル（和歌山）・太平洋アマガエルの合唱・マレーシアのカエル。
  - 哺乳類：ノロジカ・オオカミ・フクロテナガザル（ベルギー）・コウモリ（巣箱）。
  - 水の生き物：タイセイヨウマダライルカ・ザトウクジラ・イルカ（メキシコ）・庭の池の水中マイク。
- 選び方：CC0・CC BY（商用モード「BY-SAを除く」でも鳴る）、写真がある・日本の録音を優先。
- 環境音（川・雨・波・風など）と自分で読み込んだ音は、無料版でも全部鳴る。
- 一覧は data/product_tiers.json の recordings.free だけで決まる。入れ替えはここを変える。新しく足した生き物の録音は、一覧に入れない限り PRO。
- 画面：
  - PRO の生き物のタイルに「PRO」の印。
  - 無料版ではタイルを暗くし、タップすると「PRO で鳴らせます」と案内する。
  - 無料の生き物を先に並べる。
- 自律演奏（参加の候補）・試聴でも鳴らない。判定は window.__recAllowed。
- いまは課金が無効なので全部鳴る。「無料版の見え方を試す」で確かめられる。

## 2. 方針

- FREE の価値を削って有料にさせない。FREE だけで、投稿できる動画が完成する。
- PRO は、制作の能力と信頼性で料金に見合うものにする。
- 料金と音源の利用条件は別のもの。PRO に加入しても、第三者の録音を無制限に商用利用できるわけではない。各録音のライセンス（帰属表示など）は、どのプランでも守る。
- 利用者の音声と画像は端末の中だけで扱い、外へ送らない。

## 3. 課金とアクセス制御の設計（v0.57 で実装。公開は server/README.md の手順の後）
- 実装：Stripe の支払いリンク（月額）→ 課金の確認サーバー（server/worker.js）→ 署名付きの PRO の証明（ES256）→ アプリが公開鍵で確かめる。data/product_tiers.json の checkout.status を live にすると始まる。
- 以下は v0.43 の設計メモ（実装はこれに沿う）。

このアプリはいま、サーバーのない1枚のページ（GitHub Pages）。画面の表示だけで機能を制限しても、ブラウザの開発者ツールで外せてしまう。そのため、本番の課金は次の形にする。

1. **決済**：Stripe Checkout（月額・年額の2つの Price）。カード情報はアプリにもブラウザにも保存しない（Stripe の画面で入力する）。
2. **契約の管理**：Stripe Customer Portal（解約・カードの変更・請求書）。
3. **権利の記録**：小さなサーバー（例：Cloudflare Workers ＋ D1）で Stripe の Webhook を受け、利用者ごとの状態（active・past_due・canceled）を記録する。
   - 受ける Webhook：`checkout.session.completed`、`customer.subscription.updated`、`customer.subscription.deleted`、`invoice.payment_failed`、`invoice.paid`。
   - 決済に失敗した時は、一定の猶予期間（例：7日）は PRO のままにし、画面で知らせる。
4. **アプリ側**：ログイン後、サーバーから署名付きの短い有効期限の権利情報（JWT など）を受け取り、`sawwEntitlement` に反映する。
5. **制限のかけ方**：重い処理や価値の高い書き出し（24-bit の WAV・AIFF、プロジェクトの保存先）はサーバーの確認を通す形にする。画面だけの制限には頼らない。

着手前にオーナーが決めること：
- 価格の承認（$9.99 / month、$99 / year）
- 使う Stripe アカウントの確認（既存アカウントの接続状況と設定）
- サーバーをどこに置くか（Cloudflare など）
- ログインの方法（メールのリンク、Apple・Google など）

## 4. 指標（必要最小限）

個人を特定しない、集計だけのイベントにする。音声・画像・ファイル名は送らない。

- FREE：起動、タイルの再生、リールの書き出し（成功・失敗・形式）、共有ボタン、7日後・30日後の再訪
- PRO：契約の開始・更新・解約・決済失敗（Stripe 側の記録）、ライブ（ミキサー・FX）の利用、トラックの書き出し

計測はまだ入れていない。入れる前に、プライバシーの方針を画面に載せる。
