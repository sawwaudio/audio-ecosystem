# AUDIO ECOSYSTEM — DJ ミキサー・サンプラー機能の設計
**作成：2026-11-02（オーナーの要望：録音の特定の音を切り取ってリバーブ・ディレイをかけたい、DJ ミキサー的な機能、エフェクトは CDJ／DJ ミキサーを参考に）**

参考にするのは、クラブ用 DJ ミキサー（2〜4チャンネル）の操作体系：チャンネルごとのフェーダー・3バンドEQ・フィルター、拍に同期するエフェクト、サンプラー。メーカー固有の名称・ロゴ・画面デザインは使わず、一般的な名前で作る（商標と意匠に配慮）。

## 1. 全体像
```
[生き物の声]──┐
[環境音]──────┼─▶ 各チャンネル：トリム → 3バンドEQ（キル付き）→ フィルター → チャンネルFX → フェーダー ─┐
[音楽（和音・楽器）]┤                                                                           ├─▶ FX（送り）→ マスター → リミッター → 出力・録音・リール
[サンプラー]──┘                                                                           ─┘
```

## 2. 段階（自動改善で1回1段階ずつ。各段階でテストを追加）
| 段階 | 内容 |
|---|---|
| **M1 ミキサー** | 4チャンネル（生き物／環境音／音楽／サンプラー）。各チャンネル：フェーダー、トリム、3バンドEQ（HI・MID・LOW、各 −∞〜+6dB、つまみを左いっぱいでキル）、フィルター（1つのつまみ：左でローパス、右でハイパス、中央でオフ、レゾナンス固定）、ミュート、レベルメーター。マスター：音量、リミッター（クリップ防止）、レベルメーター。既存の音の流れ（自律演奏・環境層・楽器・合成の和音）を4つの系統に振り分ける |
| **M2 エフェクター（拍に同期・10種類）** | **2026-11-02 オーナー要望で10種類に。** ①ディレイ ②エコー（フィードバック強め・繰り返すたびに暗くなる） ③ピンポンディレイ（左右交互） ④リバーブ（広さ・残響時間） ⑤フランジャー ⑥フェイザー ⑦フィルタースイープ（拍に合わせてフィルターが往復） ⑧ロール（直前の音を拍の長さで繰り返す） ⑨トランスゲート（拍に合わせて音を刻む） ⑩ビットクラッシュ（ビット・サンプルレートを落とす）。操作：エフェクトの種類を選ぶボタン（10個）、拍の長さ（1/8・1/4・1/2・1・2・4拍）、ドライ／ウェット、かけるチャンネル（生き物・環境音・音楽・サンプラー・マスター）、オン／オフ（押している間だけ有効にする操作も）。各エフェクトにもう1つ専用のつまみ（例：フィードバック量・深さ・残響時間）。テンポは自律演奏のテンポ・手入力・タップで決める。テスト：10種類それぞれで、オンにすると出力が変わり（オフと差が出る）、オフで元に戻ること、フィードバックの上限で音量が発散しないこと（マスターのピークが 0dBFS を超えない）、切り替えでエラーが出ないことを確かめる。 |
| **M3 チャンネルごとの空間系** | 各チャンネルに1つのつまみで効く空間系（リバーブ量・ダブエコー・スイープ・クラッシュ（ビット落とし））。つまみ中央でオフ |
| **M4 サンプラー／スライサー** | 録音（自然録音・楽器）を選ぶ → 波形を表示 → 指でなぞって区間を切り取る → ループ・逆再生・速度／音程・フェード。パッド8個に割り当て、タップで発音（1回再生／ループ／押している間だけ）。拍に合わせて鳴らす設定。サンプラーの音はサンプラーチャンネルに入り、M1〜M3 の EQ・フィルター・エフェクトがかかる |
| **M5 書き出しと保存** | エフェクト込みで WAV 録音・リールに反映（すでに master の後段で録っているので確認のみ）。パッドとミキサーの設定をプリセットに保存。Web MIDI で DJ コントローラ・MIDI 機器から操作（フェーダー・つまみ・パッドの割り当て） |

## 3. 守ること
- **権利**：切り取り・エフェクトは「改変」。CC BY の素材は改変の旨を含めて帰属表示を出す（WAV・リールのクレジットは既存の仕組みで出る）。商用モードで対象外の素材はサンプラーにも読み込めない（代用しない）。
- **合成音を足さない**：エフェクトは音の加工であって音源ではない。ノイズなど新しい合成の音源は作らない（オーナー方針）。リバーブの残響は計算で作る（将来、CC0 の実測インパルス応答が見つかれば差し替え）。
- **音量の安全**：フィードバックの上限、マスターのリミッター、急な大音量を出さない。
- **スマホ優先**：390px 幅で片手操作。つまみは縦ドラッグ、フェーダーは縦スライダー、パッドは大きく。iPhone の遅延・負荷を確認。
- **既存機能を壊さない**：自律演奏・地域フィルター・商用モード・録音・リール・英語表示。
