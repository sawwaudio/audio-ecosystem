## 1. 実装したこと
- MIDI の欄にチェック「機器のランプを光らせる（割り当てたパッド・ボタンの状態を同じ機器へ送る）」を追加（既定は切）。
- 入れると、ノートか CC を割り当てたパッド・ボタン・「押している間だけ」の状態を MIDI 出力へ送る。
  - ノート：ベロシティ 127＝点灯／0＝消灯（ノートオン 0x9n）。CC：値 127／0（0xBn）。チャンネルは割り当てと同じ。
  - 点灯の条件：パッド＝録音が割り当て済み、ボタン＝押された状態（aria-pressed＝true、または on）、押している間だけ＝押している間。
  - 連続値（つまみ・フェーダー）の割り当てには送らない。
- 送り先は、入力と同じ名前（大文字小文字・空白を無視し、片方がもう片方を含む場合も可）の MIDI 出力だけ。名前の合わない出力（音源・シンセなど）には送らない（音が鳴ってしまうのを避けるため）。
- 0.15 秒ごとに状態を確かめ、変わった時だけ送る。入れた時と接続した時は全部の状態を送る。切った時・割り当てをすべて消した時は、送った分をすべて消灯にしてから止める。
- 保存は localStorage `ae-midi` に `out:true`（入の時だけ書く。古い保存データもそのまま読める）。
- 英語表示を index.html と build/src_i18n.js の両方に追加（完全一致）。build/src_midi.js と index.html の ae-midi 区間は同一。
- テスト用に `__midi.outRefresh(force)`・`__midi.lit(割り当て先)`。
- 版表記 v0.60（index.html と build/src_studio.js）。
