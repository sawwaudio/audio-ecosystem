# saww audio ecosystem — 見た目の方針（v0.47）

2026-11-06 のオーナー要望に対する設計です。

> 人が見て面白いと思うリール動画が欲しい。ポップさ・動き・配色の良さ。リールだけでなく画面全体も。

## 1. 方向：「図鑑のポップ印刷」

- **出発点：** 実録音の生き物を集めた図鑑を、リソグラフ（はっきりした少数の色を重ねる印刷。版が少しずれて影が出る）で刷ったような見た目にします。自然の題材でも、くすんだ「自然っぽい色」にはしません。
- **v0.46 までの問題：**
  - 地の色が暗い青緑で、文字は等幅の細い書体、ラベルは英大文字でした。計測器のような印象で、楽しさがありませんでした。
  - 色が1色（淡い緑）しかなく、見どころが分かりませんでした。
- **方針：**
  - 色は少数のはっきりした色を、役割を決めて使います。
  - 見出しは太く大きく、丸みのある書体にします。
  - 動きは「音に反応する」ものと「押した時に応える」ものに絞ります。

## 2. 色

| 名前 | 値 | 役割 |
|---|---|---|
| 夜の紙 | `#15122b` | 画面の地（深い青紫）。真っ黒より柔らかく、色が映える |
| 面 | `#1f1a3d` | 欄の面 |
| ひまわり | `#ffd447` | 主ボタン（自律演奏・リールを録画・絞り込みの選択中）、01 音を選ぶ、虫 |
| ピンク | `#ff4f9a` | 02 リール、止めるボタン、再生中の印 |
| ミント | `#2fd9a6` | 03 演奏する、水・環境 |
| 空色 | `#5b8cff` | 04 スタジオ、鳥 |
| オレンジ | `#ff8a3d` | 動物 |
| 紙 | `#fff7e8` | 文字 |

- 写真のタイルは、生き物のグループの色で光ります（鳥＝空色、虫＝ひまわり、動物＝オレンジ、水・環境＝ミント、自分の音＝紫）。鳴っている波形も同じ色です。どの音が鳴っているか、色で見分けられます。
- ライセンス区分の色（A〜C・U）は意味を持つので変えていません。

## 3. 書体

- **見出し：** Dela Gothic One。太い日本語ディスプレイ書体で、名前・欄の見出し・価格・リールの生き物名に使います。
- **本文とボタン：** M PLUS Rounded 1c（丸ゴシック、500〜900）。
- Google Fonts から読み込みます。読めない時は、端末の書体（ヒラギノ丸ゴ・ヒラギノ角ゴ）で表示します。
- 数値（つまみの値・時間）は今までどおり等幅です。

## 4. 動き

- **押した時：** タイルを押すと少し縮みます。鳴り始めると弾んで、グループの色で光ります。
- **鳴っている間：** ヘッダーの「音の花」のマーク（4色・8枚の花びら）がゆっくり回ります。止めると止まります。
- 動きを減らす設定の端末では、弾み・回転を止めます。

## 5. リール「ポップ」（新しい既定）

主役は「音で咲く花」です。

1. 生き物の写真を丸く切り抜き、太い線で縁取ります。後ろに版ずれの色の円を置きます。
2. 周りに28枚の花びらを並べます。花びらは周波数ごとの強さで伸び縮みし、ゆっくり回ります。3色の版の色で、後ろに影が付きます。
3. 鳴き始め（音の立ち上がり）で、紙吹雪が花から飛び散ります。写真と名前も少し弾みます。
4. 鳴いている生き物が替わると、写真が弾んで大きくなり、名前の文字が1文字ずつ落ちてきます。
5. 名前の文字は、それぞれ別の周波数に合わせて上下に弾みます。
6. 背景の色の塊は、低い音でふくらみ、ゆっくり漂います。
7. 下には、いまの波形を太い線で描き、いっしょに鳴っている音を色のステッカーで並べます。
8. ステッカーを2つ置きます。グループ（「鳥」「虫」など）の角丸のものと、「実録音・本物の自然の音」と書かれて回る丸いものです。
9. 印刷のざらつきを薄く重ねます。

- **配色は5種：** ひまわり（既定）・キャンディ・ラグーン・ジャングル・夜。テンプレートの選択で切り替えます。今までの区画パネル・ミニマルなどの8種も残しています。
- **クレジット：** 録音（作品名・作者・ライセンス）と写真（撮影者・ライセンス）を映像の中にも入れます。説明欄用の全文は今までどおりです。
- **文字の位置：** すべて、SNS の画面部品に隠れにくい範囲（上 220px・下 340px・右 148px を避ける）に置きます。
- **描画の負荷：** 1フレーム約0.4ms（JS 側）。

## 6. 次に試すこと

- 実機（iPhone）で、録画中の滑らかさと書体の読み込みの速さを確かめる。
- 鳴き声の種類ごとの動きの差。たとえば、鳥は花びらが細かく震え、虫は規則正しく脈打つ。
- 冒頭1秒の「つかみ」。花が閉じた状態から一気に咲く。
- オーナーが実際に投稿したリールの反応を見て、配色の人気順に既定を入れ替える。
