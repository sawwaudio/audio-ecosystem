## 1. オーナー要望と対応（2026-11-06 20:00〜20:05）
| 要望 | 対応 | 理由 |
|---|---|---|
| ロゴを使う | ヘッダーの丸いロゴ、タブのアイコン、ホーム画面のアイコン、リール「自然」の見出し | 画面とリールで同じ印を見せ、覚えてもらう |
| 生き物ごとに音量と休みを選ぶ | 詳細シートに音量（ループ・自律演奏で共通）と休み（おまかせ・休まない・5/15/30/60秒） | 数字の入力より選ぶ方が速い。2つあった音量を1つにして迷わないように |
| 写真のない生き物（合唱など）に画像 | 種類に合わせた切り絵風のイラスト（59種）。「イラスト（実写ではありません）」と明記 | 写真の雰囲気を崩さずに、姿が想像できるように。実写と取り違えないように |
| 環境音はどこ？ | 「生き物｜環境音（川・雨・波・風）」のタブ。鳴っている数も表示 | 環境音が生き物の下に埋もれていた。最初の画面から1回で届く |
| 鳴っている音をまとめて見て外す | 下のバーの「♪ 数」で一覧。写真・音量・休み・✕ | 鳴らした場所を探しに戻らなくても、その場で調整・解除できる |
| タッチで演奏はいらない | 画面から外した（処理は隠した領域に残す） | 使われない欄を減らす |
| 楽器は全部まとめる。合成音も残す | 「楽器（実録音）」（低音・旋律・打楽器）と「合成音（シンセ）」（持続音・旋律・打撃） | 実録音か合成かで探せるように。振り分けは自動（追加しても正しい欄に入る） |
| シンセの密度・重なりを増やす | 「合成音の密度・重なり」50〜400%（楽器にも同じつまみ） | 発音の頻度と同時発音の上限（最大2.2倍）を上げる。合成音だけ・楽器だけに効く |
| 楽器を増やす。毎日少しずつ | カリンバ・マリンバ・チューブラーベル・グロッケンシュピール（各5本）。自動作業のバックログ E に手順と候補 | 旋律の実録音が2種しかなかった |

## 2. 追加した録音（VCSL・CC0 1.0、固定コミット c1ea7bcc）
- カリンバ（ケニアのムビラ）5本、マリンバ5本、チューブラーベル5本、グロッケンシュピール5本。計20本。FLAC 5.4MB（原本 PCM とビット単位で同一）と互換 MP3 2.4MB。
- 音高はすべて実測した。
  - カリンバ・マリンバ・グロッケンシュピールは、VCSL の音名より1オクターブ上が実際の基音。
  - カリンバは平均律ではないため、測った値（小数）を使う。
  - チューブラーベルは倍音（第4〜6モードが 2:3:4）から求めた打音の高さが音名どおり。
  - 他の弦の共鳴で音高が決められなかった1本（カリンバ B4）は入れなかった。
- 鳴らし方：いまの和音の音を楽器の音域へオクターブで移し、1〜4音の短いフレーズにする（REAL_DEF の mode:'melody'）。
- 音量：ミキサー「音楽」のピークが既存の楽器と同じ程度（値70で −18〜−24 dB）。初期値は 0（選んだ人だけ鳴る）。
