# saww audio ecosystem — 画面の並びと、その理由（v0.45）

> **v0.61（2026-11-07）で並びを変更**：オーナーの指示で「リールを作る」を3番目にした。いまの並びは 01 音を選ぶ → 02 演奏する → 03 リールを作る → 04 スタジオ → プラン → 設定と権利。下の表は v0.45 の時の理由として残す（リールの「2番目に置きます」は、いまは3番目）。

2026-11-06 のオーナー要望に対する設計です。要望は次の3つでした。

- 写真のタイルと「この音場に加える」が重複しないようにする。
- 説明文を減らす。見たい人だけが開けるようにする。
- 機能を上からどの順に載せるかに、使いやすさの理由を込める。

## 1. 基本の考え方

1. **音を選ぶ入口は1か所（写真のタイル）。** 同じことを2つの画面でできると、「どちらで選んだ音が鳴っているのか」が分からなくなります。
2. **上から下へ「やりたいこと」の順に並べる。** 開いた人の多くがまずやりたいことを上に置き、慣れた人が使う細かい道具を下に置きます。
   - 開いた人の多くがまずやりたいこと：聴く → 動画にする → 共有する
   - 慣れた人が使う道具：整える → 録る → 書き出す
3. **1つの欄に見せる文は1行だけ。** 残りの説明は「ⓘ 詳しく」に入れます。文言は消さず、開けば今までどおり読めます。
4. **止めるボタンは、いつも親指の届く場所に置く。** スクロールしても下のバーから止められます。

## 2. 上からの並びと理由

| 順 | 欄 | 置いた理由 |
|---|---|---|
| — | ヘッダー（名前・言語・状態） | 何のアプリか、いま鳴っているか（● LIVE）だけを示します。ボタンは言語の切り替えだけにしました。 |
| — | ページ内の移動（01〜04・設定） | ページが長いので、どこに何があるかを最初に見せます。番号は作業の順番で、画面を上から読む順と同じです。スクロールしても上に残ります。 |
| **01** | **音を選ぶ（写真のタイル）** | 最初の1回のタップで音が出る体験が、このアプリのいちばんの価値です（See it. Tap it. Hear it.）。説明を読まなくても写真を押せば分かるので、最上段に置きます。「自律演奏」ボタンもここに置き、タイルを押した後すぐに押せるようにしました。 |
| | ・最初は12枚だけ（列数に合わせて行をそろえる） | 127枚を全部並べると、次の「リール」まで約1万ピクセルのスクロールになります。12枚にして、1〜2回のスクロールでリールに届くようにしました。残りは「すべて表示」と絞り込み（鳥・虫・日本…）で探せます。 |
| **02** | **リールを作る** | FREE プランの目的は「作って共有する」です。音が決まった直後にやることなので、2番目に置きます。設定は「長さ・テンプレート・画像」の3つだけを見せ、「● リールを録画」を目立つ色にしました。 |
| **03** | **演奏する**（自律演奏の和音・量・組み合わせ → タッチ演奏 → シンセの層） | 写真で選んだ音を「育てる」段階です。よく触るもの（和音・全体の量）を上に、まれにしか触らない合成音の層を閉じた状態で下に置きました。シーン・地域の組み合わせは、タイルで1つずつ選ぶ代わりにまとめて選ぶ近道なので、ここに畳んであります。 |
| **04** | **スタジオ（PRO）**：ミキサー → サンプラー → トラックと録音 | 制作の流れの順です。鳴っている音を整え、素材を切り取り、重ねて書き出します。ミキサーは準備なしで今の音に効くので先頭です。録音・書き出しは最後の工程なので末尾に置き、録音機能（WAV の録音・マイク・出音の録音）はトラックの欄にまとめました。 |
| — | プラン（FREE / PRO） | スタジオで PRO の印を見た直後に、価格と違いを確かめられる位置です。音を鳴らす前には価格を見せません。 |
| — | 設定と権利（商用モード・プリセット・クレジット・音源の形式・診断） | 毎回は触らないけれど、必要なときには必ず見つかる必要がある項目です。いちばん下にまとめました。商用モードは常に開いておき、選択肢がすぐ見えるようにしています。 |
| — | 下のバー（いま鳴っている音・■ 止める・● リール） | 何かが鳴っている間だけ出ます。どこまでスクロールしても、止める・リールへ移るが1タップでできます。iPhone の親指の届く位置（画面下）に置き、ホームバーの余白（safe area）も取っています。 |

## 3. 重複をなくした内容

| 以前 | v0.45 |
|---|---|
| 写真のタイル（ループで鳴らす）と、生き物の一覧の「＋ この音場に加える」「▶ この録音を聴く」（自律演奏に参加させる） | **タイルだけ**にしました。自律演奏が止まっているときにタップするとループで鳴り、自律演奏中にタップすると参加・不参加が切り替わります（休みを挟んで鳴く）。自律演奏を始めると、ループで鳴っていた音はそのまま参加メンバーに引き継ぎ、同じ音を二重には鳴らしません。 |
| 生き物ごとの「この声の音量」「休息（秒）」 | タイルの詳細シート（長押し・i）の「自律演奏のとき」に移しました。 |
| 環境音の層の音量一覧（31本のスライダー） | 環境の録音のタイルで、オン・オフを切り替えます。音量は詳細シートで調整します。 |
| 実録音ライブラリの個別試聴ボタン（127個） | タイルで代わりができます。 |
| 「■ すべて止める」「● リールを作る」がタイルの下にあった | 下のバーに移しました。どこからでも押せます。 |
| LIVE CAPTURE（WAV の録音）が独立した欄 | 「トラックと録音」の中に移し、録る機能を1か所にまとめました。 |

画面から外した一覧（生き物・環境音）は、隠した領域（`#legacyLists`）で今までどおり動いています。自律演奏・プリセット・地域の絞り込みは、これまでと同じ設定を読み書きします。

## 4. 説明文の扱い

- 各欄に見せる説明は1行の要約（`.lead`）だけです。
- それ以外の説明（操作のしかた・ライセンスの注意・技術的な制約）は、すべて「ⓘ 詳しく」（`details.help`）に入れました。最初は閉じています。
- 状態の表示（読み込み中・再生中・エラー）は説明ではないので、そのまま見せます。
- テスト（`build/test_ui_v045.js`）で、閉じた状態の画面に60文字を超える説明文がないことを確かめています。

## 5. 楽器の層（同日のオーナー要望）

- 音程のある楽器から「弦のハーモニクス」「息のあるフルート」（どちらも合成音）を外しました。タッチ演奏の音色からも外しています。
- 低音ドローンに実録音を6種足しました。
  - VCSL・CC0 の楽器5種：ディジュリドゥ、パイプオルガンのペダル、ティンパニのロール、ゴングの余韻、ピアノの最低音域。
  - 自然の低音1種：CC0 の波の録音（ビッグラグーン）から、170Hz より下の帯域だけを取り出したもの。
  - 持続音はいまの和音の根音に合わせ（±6半音以内の速度変換）、切れ目をクロスフェードでつなぎます。
- 打撃・脈動に実録音を5種足しました：フレームドラム、カホン、ダルブッカ、スリットドラム、コンガ。
  - 鳴らし方は、1〜4打の短いフレーズです。間隔は BEAT FX のテンポの8分音符です。
- 音量は、既存の層とソロで聴き比べたときのピークと RMS がそろうように調整しました。
- 合成音のドローン（低音ドローン・オルガン持続音・擦弦持続音）と、合成の打撃（心拍・キック・石）は残しています。

## 6. 今後の課題

- iPhone 実機で、下のバーと上の移動バーの高さ・親指の届きやすさを確認する。
- タイルの並び順（写真のある種を先頭）を、季節や人気で入れ替える。
- 「シンセの層」の合成音を、実録音に置き換えられるものから順に置き換える（LIBRARY_300_PLAN の C）。
