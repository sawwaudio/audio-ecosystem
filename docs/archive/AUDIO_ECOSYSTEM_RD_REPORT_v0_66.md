## 1. 課題
- CC BY の素材は、使う人が作品名・作者・ライセンスを表示する必要がある。リールはこれまで説明欄用の .txt とテンプレートごとの「いま鳴っている1件」の表示だけで、動画が説明欄なしで転載されると、録画中に鳴った他の CC BY の素材の帰属が映像に残らなかった。
- 調べる中で、テンプレート「自然」「ポップ」の録画中の経過時間が「NaN:NaN」と描かれていることが分かった（存在しない reelState.t0 を参照）。

## 2. 変えたこと
- 録画の最後の数秒（長さ÷5、2〜4秒。15秒で3秒、30秒以上で4秒。録画を始めた時の長さで決める）に、どのテンプレートでも画面を暗くして「音のクレジット / Sound credits」を重ねる。
  - 表記が必要なもの（CC BY・CC BY-SA）：名前（和名 / 英名）と「"作品名" — 作者 · ライセンス」を全部。表記が必要な写真も同じ形で。
  - 表記不要（CC0・PD）：件数だけ。利用者がインポートした音は入れない（権利は利用者が確認）。
  - 入りきらない時は「+ N 件は説明欄に / more in caption」。下に「全クレジットは説明欄 / Full credits in caption」。
  - 文字は SNS の画面部品に隠れにくい範囲（REEL_SAFE：上220px・下340px・右148pxを避ける）に置く。日本語と英語を併記（映像の文字は画面の言語切り替えの対象外のため）。
- 「■ 停止して書き出し」：クレジットがまだなら同じ秒数映してから書き出す（状態表示「● REC n / N SEC · CREDITS」。もう一度押すとすぐ書き出す）。
- リールの設定に「最後にクレジットを映す」（既定オン）。英語は Show credits at the end（build/src_i18n.js と index.html の辞書の両方）。
- 書き出し結果（__reelDebug の result）に endFrames・endLines・endCut を追加（テスト用）。
- 「自然」「ポップ」の経過時間を reelState.startedAt から求めるよう修正。分析テンプレートの「/ N s」は整数表示。
