# SAE Reels 投稿管理

Macの専用ユーザーで使うローカル管理画面です。「投稿管理を開く.command」をダブルクリックしてください。Macにログイン中でスリープしていれば、19時の投稿は遅延または失効します。時計は日本時間です。状態と出力は ~/Library/Application Support/saww-reels に残ります。

## 初回設定

Python 3、requirements.txt、ffmpeg、Node.js、Playwright、Chromeが必要です。install_mac.py --help で実行ファイルとSAEライブラリの保存場所を指定できます。インストーラーはmacOSのLaunchAgentを登録します。ブラウザーによる実演収録にはSAE公開サイトへの接続が必要です。

## Metaとの接続

Facebook Login方式を使います。対象のInstagramプロアカウントとFacebookページをリンクし、Metaのアプリで公開・インサイト取得に使う権限を設定します。この方式ではFacebookログイン用のトークンを使用します。Metaアプリで使用しているGraph APIバージョンとInstagramプロアカウントの数値IDを `python3 setup_meta.py` で設定してください。

「キーチェーンアクセス」でログインキーチェーンに新しいパスワード項目を作成します。項目名は `saww-reels`、アカウントは `meta`、パスワード欄にアクセストークンを入力します。実行ユーザーから項目にアクセスできることを確認して `python3 desk.py check-meta` を実行してください。期限・失効時にはMetaで再認証し、同じ項目の値を更新してください。トークンの自動交換は未実装です。

管理画面で再生・権利表記・キャプションを確認し、公開する日の「承認」を押します。18:50からコンテナを用意し、19:00以降に処理完了を確認して公開します。手動処理ボタンは今日の承認済み動画を準備／公開できます。DRAFTは生成のみ、APPROVALは個別承認制、AUTOは品質検査に合格した動画を公開します。AUTOへの切替には管理者の操作と初回の公開記録が必要です。

各日1件をSQLiteで管理します。公開応答を取り損ねたら、日付タグが一致する投稿を照合します。一致しない場合は未確定のまま保持します。失敗した動画は管理画面で理由を確認し、必要に応じて再生成・再承認してください。Macで誰でもアクセスできる共有プロキシには接続しないでください。

## 制作

render.py SERIES --root SAE_DIRECTORY --out DIRECTORY --seed NUMBER がMP4、1秒地点のカバー、キャプションと権利ログを生成します。makeとcreateは先に node capture.cjs DIRECTORY を実行し、同じディレクトリを --stills で指定します。実演はSAEの無料UIから雨と波を重ね、内蔵の録画器・クレジットを確認します。他シリーズは実録音を解析して別々の構成を描きます。音源のハッシュ・作者・ライセンスURL・出典を確認できない場合は停止します。

直近30日間のシリーズと主音源を参照します。週ごとの配分には過去8週の保存・共有／リーチを使い、5本以上測定済みのシリーズが3つ以上になってから週1枠を振り替えます。管理画面に未取得の指標はゼロとして表示しません。プロフィールからSAEの無料利用・契約に至った件数の計測は未接続です。

テストは `python3 -m unittest discover -s . -v` です。Metaへの認証・実投稿テストは別途必要です。

## SAEの管理者権限

このMacのオーナーは「管理者としてSAEを開く.command」を開いてください。公開版の「05 設定」に「管理者 · PRO機能を利用できます」と表示されます。投稿管理画面の「SAEを管理者として開く」からも入れます。管理者セッションはタブ単位で最長1時間です。終了操作または期限到来で、そのブラウザーの通常のFREE／購入済みPROの状態に戻ります。

起動用のリンクは90秒、1回限りです。投稿管理のCookieは8時間で失効します。SAEの利用証明は本番サイト用の署名付き証明で、StripeやInstagramの操作には使えません。発行鍵はこのMacの利用者専用ファイルに保管します。新しいMacに移行する場合は、既存の発行鍵を安全に移すか鍵を更新し、公開サイトの検証鍵と対応させてください。既存のStripe契約がある場合、その契約の管理は管理者モードを終了すると表示されます。

### 登録したブラウザーで自動的に開く

「管理者としてSAEを開く.command」は、最初の1回でMacの標準ブラウザーを登録します。以後は通常のSAEのURLやブックマークから開けます。上記の1時間の制限は旧方式の一時セッションに適用されます。

iPhoneや別のブラウザーでは https://sawwaudio.github.io/audio-ecosystem-sounds-1/?setup=device を開きます。表示された登録コードを、Macの投稿管理の「ほかの端末を登録」に入力し、承認リンクをコードを出したブラウザーで開きます。承認リンクはそのブラウザーの秘密鍵と組み合わせて初めて有効です。秘密鍵は書き出せないCryptoKeyとしてブラウザーのIndexedDBに保存します。登録状態はブラウザーおよびプロファイルごとです。

05 設定の「このブラウザーの管理者登録を解除」はその鍵と証明を削除します。サイトデータを消したときやプライベートウインドウを閉じたときも、通常ウインドウで登録し直してください。この方式はオフラインでも署名を検証できます。紛失した端末の個別遠隔解除には対応していません。署名の検証鍵を公開版で更新すると、その旧鍵の証明をまとめて無効にできます。投稿の管理操作は従来のMacの本人確認が必要です。
