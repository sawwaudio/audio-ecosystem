# AUDIO ECOSYSTEM R&D レポート v0.36 — DJ ミキサー（第2段階 M2：拍に同期するエフェクト）
**2026-11-02 17:35 JST（自動実行）／設計：docs/DJ_MIXER_SPEC.md**

## 1. 何ができるようになったか
「ミキサー / MIXER」の欄の下に「BEAT FX / エフェクト」を追加した。エフェクトは1台で、次の操作がある。
| 操作 | 内容 |
|---|---|
| 効果 | ディレイ、エコー、ピンポンディレイ、リバーブ、フランジャー、フェイザー、フィルタースイープ、ロール |
| 拍の長さ | 1/8・1/4・1/2・1・2・4 拍（最大8秒） |
| かける先 | マスター、生き物、環境音、音楽、サンプラー |
| テンポ | 手入力（40〜200 BPM）と TAP（直近4間隔の平均） |
| ドライ／ウェット | 0〜100 |
| オン／オフ・押している間だけ | 押している間だけは指・マウス・Space/Enter で動く |

拍の長さの意味：ディレイ・エコー・ピンポンは繰り返しの間隔、リバーブは残響の長さ（拍の2倍）、フランジャー・フェイザー・スイープは揺れの周期、ロールは繰り返す長さ。

## 2. 作り
- **差し込み位置**：マスターはコンプレッサーの後・リミッターの前（楽器の直結経路も通る）。チャンネルは、そのチャンネルのすべてのレーン（dry・wet・direct）の出力の後ろ（フェーダー・ミュートの後）。最初にオンにするまでは何も差し込まず、音の経路は v0.35 と同じ。
- **各効果**
  - ディレイ：帰還 0.38。エコー：帰還 0.62、ループ内に 2.6kHz ローパスと 120Hz ハイパス（繰り返すたびに暗くなる）。
  - ピンポン：入力をモノラルにして左→右→左と交互に（帰還 0.5）。
  - リバーブ：計算で作る残響（2ch・指数減衰）、150Hz ハイパスの後に畳み込み。
  - フランジャー：5ms±2.2ms の変調ディレイ・帰還 0.5。フェイザー：オールパス4段（1kHz±800Hz）。フィルタースイープ：ローパス（1.9kHz±1.7kHz、Q4）。
  - ロール：押した瞬間の直前1拍をループに閉じ込めて繰り返す（入力を止め、帰還を 1 に）。
- **ドライ／ウェット**：ディレイ系・リバーブ・フランジャー・フェイザーは原音に加える。スイープとロールは原音と入れ替える（クロスフェード）。
- **余韻**：ディレイ・エコー・ピンポン・リバーブはオフにしても余韻が自然に消える（入口だけ閉じる）。
- **安全**：帰還はロール以外 0.62 以下。どの差し込み位置でもリミッターが最後に効く。新しい音源は作らない。

## 3. 発見：帰還ループの遅れ（Chromium）
Chromium では、帰還ループを1周するたびに 128 サンプル（処理単位1つ分）余計に遅れることを実測した（ピンポンでは右側の1回目も 128 遅れる）。そのままだと繰り返しの間隔が 1/2拍（120BPM で 12000 サンプル）から 12128 サンプルにずれ、ロールでは境目に音が二重になる。
- 対処：読み込み時に OfflineAudioContext で遅れを実測し（`FX_CAL`：a＝1回目の遅れ、x＝1周ごとの余分な遅れ、ピンポンは左右別）、ループ外の前置ディレイ P とループ内のディレイ長 D で打ち消す（1本のループ：P＝x−a、D＝拍−x）。
- ロールは、前置ディレイの中の音が入り切るまで入口を開けておき、帰還は x だけ遅らせて開く（Chromium では帰還ゲートの前で遅れるため）。
- 実測値（Playwright 同梱のヘッドレス Chromium 153.0.8010.12）：a=0、x=128、aL=0、aR=128、xp=128。

## 4. 検証（build/test_fx.js、すべて合格）
| 項目 | 結果 |
|---|---|
| 差し込んだだけ（オフ） | 原音とサンプル単位で一致（誤差 0） |
| ディレイ（120BPM・1/2拍） | 12000・24000・36000 サンプル目に 1・0.38・0.144 |
| エコー | 1回目はそのまま、2回目以降は山が低く広がり（暗く）、弱くなる |
| ピンポン | 左のインパルス → 左 0.5 → 右 0.5 → 左 0.25（反対側は 0） |
| リバーブ | 残響が 0.5 秒（拍の2倍）で終わる |
| フランジャー・フェイザー・スイープ | 音が変わり、発散しない。スイープは拍の周期で明るさが変わる |
| ロール | 1.0 秒で押すと 0.75〜1.0 秒の音を3周にわたりサンプル一致で繰り返す（誤差 1e-4 未満） |
| 操作 | 拍ボタン、TAP（0.5 秒間隔で 120BPM）、BPM の上限、押している間だけ（指・キーボード） |
| 実演奏 | マスター・環境音への差し込み、音が出る、M1 のレーン構成はそのまま |
| 英語・画面幅・エラー | 未翻訳0、390px で横にはみ出さない、エラー0 |

既存テスト（mixer・i18n・v024 の126ファイル照合・geo・rights・badges・preset_rights・attribution・beds・japan_beds・memory・reel・v033）もすべて合格。リールの書き出し（5秒）も合格。
