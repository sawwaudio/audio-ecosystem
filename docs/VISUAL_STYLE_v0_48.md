# saww audio ecosystem — 見た目の方針（v0.48）

2026-11-06 19:22 のオーナー要望に対する設計です。v0.47 の「ポップ」からの見直しです。

> ポップでいいけど、自然の美しさ・自然な雰囲気を犠牲にしている。それを保ちつつ、ポップさと高級感を出したい。いまはカラフルすぎる。生き物の姿は見えた方がいい。色を一部取り入れるのはいい。

同じ日の 19:33 の要望も入れています。

> 岩場や水の音は、虫や鳥と並べずに環境録音（小雨・川の流れなど）にまとめる。生き物は虫・鳥・水中の生き物・両生類・哺乳類のように分ける。

## 1. 考え方
- **色は写真から取る。** 生き物と自然の色そのものが一番美しいので、こちらで色を決めず、写真の中から選びます。
  - 地の色：写真の暗い部分の色を、さらに暗くしたもの。
  - 差し色：写真の中のいちばん鮮やかな色を1つだけ。
  - これで、生き物ごとに配色が変わります。カワセミなら青、紅葉の中の鳥なら赤みのある色になります。
- **生き物の姿を主役にする。** リールの上6割を写真にし、ゆっくり寄りながら流します（ケン・バーンズ）。図や文字で写真を隠しません。
- **高級感は、文字と余白と動きの静けさで出す。**
  - 和名は明朝（Shippori Mincho B1）、学名はイタリックのセリフ体（Cormorant Garamond）にします。図鑑の1ページの組み方です。
  - 動きは「ゆっくり・細く」にします。弾む・飛び散る動きはやめました。
- **ポップさは「音への反応」と差し色1色で出す。** 次の3つを、写真の差し色で描きます。
  - 写真の下端から生える細い線（周波数ごとの強さ）
  - 光の波形
  - 鳴き始めの細い光の波紋

## 2. リール

| テンプレート | 内容 |
|---|---|
| **自然（写真の色）＝既定** | 暗い地に、写真を全面の上6割に置く。下へ溶けるように地の色へつながる。文字は写真の下：番号と分類（差し色）・和名（明朝）・学名（イタリック）・英名・録音地と年・録音と写真のクレジット・「ともに鳴く」ほかの音 |
| 自然・紙（図版） | 明るい紙の地に、写真を細い枠の図版として置く。図鑑の紙面のような版 |
| ポップ5配色（v0.47） | 選べるように残した |

- 生き物が替わると、写真は1.2秒かけて重なりながら入れ替わります。文字は1行ずつ静かに浮かび上がります。
- 音で写真がわずかに明るくなり、寄る量も少し増えます。
- 薄いフィルムの粒を重ねます。
- 写真がない音は、分類の色の淡い光と細い輪で表します。

## 4. 生き物と環境音を分けた（19:33 の要望）
- **生き物：** 鳥 32・虫 23・両生類 19・哺乳類 12・水の生き物 11。
- **環境音：** 30。雨・川・波・風・森などを、生き物の写真の下に別の欄「環境音」として横に並べます。それぞれ、雨・水の流れ・波と岩・風と森・火・嵐・氷の線画を付けます。
- **分類の根拠：** `data/sound_categories.json` に、1件ずつ根拠と一緒に記録しました。
  - 決め方は、録音台帳の種別・グループ・名前（原典の記載）です。種名は推測しません。
  - 生き物の合唱が主の環境録音は、生き物の側に入れました。虫の合唱（柏）、セミの合唱（東京の公園・中目黒）、水田のカエルの合唱です。
  - 種名の記載がない「アマゾンの夜の森」は、環境音に入れました。
- **絞り込み：** すべて・鳥・虫・両生類・哺乳類・水の生き物・日本・写真あり・自分の音・再生中。
  - 分類の絞り込みは、生き物の欄だけに効きます。
  - 環境音の欄には、日本・再生中などの絞り込みだけが効きます。
