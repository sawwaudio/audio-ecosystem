# 映像テンプレート organic・particles・geometry（v0.66）
2026-11-09。リールの「テンプレート」に3つを追加した（既定は従来どおり「自然（写真の色）」）。

## 1. 音との対応
- 解析：既存の reelMoFeatures（低域 40〜250Hz・中域 250〜3kHz・高域 3〜12kHz、RMS、フラックスによる立ち上がり）をそのまま使う。
- organic：低域＝光の塊の大きさ、中域＝輪郭のゆらぎ、高域＝細い線の震え、立ち上がり＝ごく淡い光。
- particles：RMS と高域で粒子の数、低域で中心への集まり、立ち上がりで中心から一度に広がる。
- geometry：低域＝多角形の大きさ、中域＝放射線の長さ、高域＝縦の細い線の震え、立ち上がり＝中心の輪。

## 2. 光過敏への配慮
- 「光の点滅を抑える」（既定でオン）。オンの時：明るさの変化をゆっくりにし、立ち上がりの反応は1秒に3回までにする（WCAG 2.3.1 の目安）。
- テストで、10秒の実音で1秒あたり最大3回以内を確認（test_visual_v066.js）。

## 3. 権利の表示
- 映像の下部に、いま鳴っている実録音の名前・作者・ライセンスと、商用モードの表示を入れる（帰属表示を映像にも残す）。

## 4. テスト（build/test_visual_v066.js）
- 3つが選べる、描画が空白でない（3つとも輝度のばらつきを確認）、点滅を抑える時の上限、15秒の書き出し（1080×1920・音あり・約15秒）。
- 既存：test_ui_v045・test_reel・test_reel_motion（テンプレート一覧を更新）・test_midi_v060 は ALL PASS。

## 5. 未検証
