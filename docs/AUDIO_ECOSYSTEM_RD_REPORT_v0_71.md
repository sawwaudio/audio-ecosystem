## 1. 課題
- 楽器サンプル（実録音のハープ・ビブラフォン・VCSL の伝統楽器など）は v0.70 では半音単位のまま鳴らしていたため、A4＝432Hz・純正律の合成音と重ねると約 −31.8 セント（＋和音の各音で −15.6〜+21.5 セント）ずれる。
- 書き出した WAV・リールのクレジットに、どの音律で作ったかが残らなかった。

## 2. 変えたこと
- 「楽器サンプルも合わせる（録音の再生速度を変えます）」のチェックを「基準 A4」「音律」の隣に追加。**既定はオフ**（録音を無断で変えない原則を守る）。
  - オフ：従来どおり 2^(半音/12) の再生速度。
  - オン：再生速度＝鳴らしたい周波数÷サンプルの公称周波数（**440Hz・平均律で録音されたとみなす**）。対象はハープ・ビブラフォン（自律演奏とタッチ演奏）、実録音の楽器層（和音の根音合わせ・旋律・持続音）。
  - 440Hz・12平均律では、オンでも従来と同じ速度（誤差 2×10^-16）。
  - 自然録音・環境層・サンプラーのパッド（利用者が自分で音程を決める）は対象外。
- 設定は `tuning.samples` として基準・音律と一緒に端末に記憶し、プリセットにも保存（旧プリセット・指定なしはオフ。真偽値以外は拒否）。
- 書き出しのクレジット（WAV の埋め込み・クレジット .txt・ミックスダウン・リール）に1行を追加：「音律 / Tuning: A4 = 432 Hz · 5-limit 純正律 / 5-limit just intonation（合成音 / synthesized tones） · 楽器サンプル / Instrument samples: 半音単位（録音のまま） / semitone steps (as recorded)」。書き出した時点の設定。全素材の一覧（library）には入れない。
- 英語の文言を build/src_i18n.js と index.html の辞書に同じ行で追加。

## 4. 未検証
- 個々の楽器サンプルの実際の音高（本当に A4＝440Hz・平均律で録られているか）は計測していない。ずれていれば、オンにしても合成音と完全には合わない。
- 耳での確認（再生速度を変えた時の音色・長さの変化、うなり）。実機。
- 録音の途中で音律を変えた場合、クレジットには書き出し時点の設定だけが残る。
