# AUDIO ECOSYSTEM — ロードマップ（逆算）
**作成：2026年11月1日**
**ゴール：世界最高の自然音の仮想楽器を作り、Instagramのリールで知られ、Stripe決済で販売する。**

---

## 0. ゴールの定義

| 項目 | 状態（ゴール時点） |
|---|---|
| 製品 | ブラウザで動く仮想楽器。iPhone・Mac・PCで発音が安定し、ホーム画面に追加して使える（PWA） |
| 音 | 非圧縮（WAV/AIFF、48kHz/24-bit以上が中心）の実録音ライブラリ。出典・ライセンス・分布・録音地を全件管理 |
| 演奏 | タッチ演奏＋自律生成（鳴き交わし・時間帯・季節・地域・生息環境）。録音・書き出し |
| 言語 | 日本語が標準。ボタン1つで英語に切り替え（UI・種名・説明・クレジットすべて） |
| 集客 | 自律生成の様子をリール動画（縦1080×1920・30〜60秒）で継続投稿 |
| 販売 | Stripeで決済。無料版と有料版。特定商取引法に基づく表記・利用規約・返金方針を整備 |

### 「世界最高」の基準（これで競合と比べる）
1. **音の正しさ**：本物の録音のみ。種名・分布・録音地を混同しない。合成の鳴き声を使わない。
2. **音質**：非圧縮・高サンプルレート。ノイズ・クリップの管理。
3. **演奏性**：遅延が少なく、タッチ・キーボード・MIDIで弾ける。
4. **生成の知性**：同じ繰り返しにならない、生態として自然な鳴き交わし。
5. **日本の自然**：公開ライブラリにほとんど無い日本の生物音（調査で判明した空白）を、自前録音（伊豆など）で埋める。**これが最大の差別化。**

## 1. 逆算スケジュール

販売開始を **2027年3月**（春の鳴く生き物の季節の前）に置き、逆算する。

### フェーズ4：販売開始（2027年3月）
- Stripe本番決済の開始、ローンチ用リールの集中投稿。
- 前提：フェーズ3が完了し、待機リスト（メール登録）がある程度集まっている。

### フェーズ3：販売の準備（2027年2月）
- **決済**：Stripe Payment Links か Checkout。購入後に有料機能を解放する仕組み（ライセンスキーまたはアカウント）。
- **価格設計**：無料版（収録数・書き出しを制限）／有料版（全ライブラリ・WAV書き出し・商用利用可の出力）。買い切りかサブスクかを競合調査で決める。
- **法務**：特定商取引法に基づく表記、利用規約、プライバシーポリシー、返金方針。音源ごとの帰属表示（CC BY）を製品内に常設。生成した音の商用利用条件を明記（CC BY-SA素材は使わない方針を維持）。
- **独自ホスティング**：claude.aiのアーティファクトは試作用。販売版は独自ドメインで公開（GitHub Pages / Cloudflare Pages など）。
- **オーナーの作業**：Stripeアカウント開設と本人確認、事業者情報、ドメイン取得（アカウント作成・決済設定は私にはできない）。

### フェーズ2：製品の完成度（2026年12月〜2027年1月）
- PWA化（オフライン・ホーム画面追加）、iPhoneでの発音・メモリの安定化。
- 初回ガイド、プリセット管理、デザインの統一、アクセシビリティ。
- 自律生成の高度化：鳴き交わし、時間帯・季節モデル、密度、空間配置、ドローン／グラニュラー。
- MIDI入力（Web MIDI）、録音のWAV／動画書き出し。
- ライブラリ拡充：調査済み候補の取り込み完了、日本の生物音の自前録音を開始。

### フェーズ1：リールを作れる状態（2026年11月16日〜12月15日）
- **リールモード**：縦長の映像（波形・スペクトログラム・いま鳴いている生き物の名前と録音地）と音を同時に記録し、MP4（H.264/AAC）で書き出す。30〜60秒。
- **自動レンダリング**：クラウド上で自律生成を再生→動画化するパイプライン（ヘッドレスブラウザ＋ffmpeg）。定期実行で毎週数本の素材を作る。
- **投稿**：Instagramへの投稿はオーナーが行う（公開投稿は毎回オーナーの確認が必要。Instagram用の接続は現状なし）。キャプション案は日英で用意。
- 待機リスト用のランディングページ（日英）。

### フェーズ0：土台（2026年11月1日〜15日）※いまここ
- **販売前提の権利整理**（2026-11-01 追加、`docs/COMMERCIAL_POLICY.md`）：商用モード（ライセンス区分フィルター）、BY-SA 17本の置き換え開始、コードの権利表示（LICENSE）、製品名の検討。
- **音源の置き場所を決める**：調査済み候補は原本で約10GB（既存候補39本 約1.6GB＋追加68本 約9.2GB）。claude.aiの公開ページは1版あたり合計256MBが上限で、試作版でもすでに約200MBを使っている。原本マスターはオーナーのMac（または外付け・クラウドストレージ）に保管し、アプリ用には演奏用の切り出し（24-bit WAV）を作る。販売版のホスティング（Cloudflare R2 / Pages など）をフェーズ3から前倒しして決める。
- ダウンロード済み・ダウンロード予定の全音源を取り込み（v0.25）。日本録音の虫の合唱・水田のカエル・竹林で Japan モードの環境層を鳴らす。
- **日本語／英語切り替え**（ボタン1つ）：画面右上のボタンで即時切替、選択を記憶。UI文言・種名（和名／英名）・説明・ライセンス表記・エラー表示まで対象。文言は辞書ファイル（ja / en）に集約し、新しい文言は必ず両方に追加する。
- 帰属表示（CC BY）の自動表示、ライセンス台帳の更新。
- iPhone Safari 実機での発音確認（オーナーの協力が必要）。

## 4. 主なリスク
- **権利**：CC BY の帰属漏れ。生成物の商用利用条件の誤り → 台帳と画面表示を自動生成で一元化する。
- **iPhone**：Safari の音声制約・メモリ上限 → 実機確認を早めに行う。
- **ホスティング・容量**：アーティファクトは販売に使えず、容量も256MBまで → 音源の置き場所をフェーズ0で決め、販売版ホスティングはフェーズ1〜2で用意する。
- **音源の独自性**：公開音源だけでは差別化が弱い → 自前の日本録音が鍵。
