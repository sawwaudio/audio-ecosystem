## 1. キー（調）
- 「演奏する」の和音の欄に、キー（12：C・D♭・D・E♭・E・F・F♯・G・A♭・A・B♭・B）と、メジャー（明るい）／マイナー（暗い）を追加。
- 和音の並び（6つ）の形はそのまま、根音を移す。C〜F♯は上へ、G〜Bは下へ移すので、音域が大きく偏らない。
- マイナー：Xm9 → ♭VImaj9 → IVm9 → ♭VII6/9 → ♭IIImaj9 → Xm11。
- 選んだキーは端末に保存（localStorage 'saww.key'）。演奏中に変えると、次の和音から新しいキーで鳴る。
- 既定は C メジャー（これまでと同じ）。

## 3. リールの画面
- プレビュー（縦の画面）を上に。その下にテンプレートを「小さな見本つきのボタン」で横に並べた（音に反応・自然・ポップ・パネル・シンプルの5群）。押すとプレビューが動き出す。
- 長さは 15・30・45・60 秒の4つのボタン。画像の選択と「光の点滅を抑える」はその下。
- 「リールを録画」を幅いっぱいの主ボタンに。プレビューと停止はその下に並べた。
- 元の select（#reelStyle・#reelLength）は見えない形で残し、値をそろえる（既存のテストと自動レンダリングの互換のため）。
