## 2. 実装した内容
- 並び：01 音を選ぶ → 02 リールを作る → 03 演奏する → 04 スタジオ（PRO）→ プラン → 設定と権利。上にページ内の移動、下に再生バー。
- タイルが音場の唯一の入口。
  - 自律演奏が止まっている時のタップはループ。
  - 自律演奏中のタップは参加・不参加の切り替え。
  - 自律演奏を始める時、ループで鳴っていた音を参加メンバーに引き継ぐ。
  - 環境の録音のタイルは、環境層のオン・オフ。
- 生き物ごとの音量・休息は、詳細シートに移した。生き物の一覧と環境音の一覧は、画面から外した（処理は残っている）。
- 説明文は「ⓘ 詳しく」に畳んだ（13か所）。見えるのは1行の要約と状態の表示だけ。
- 楽器：
  - フルート・弦のハーモニクス（合成）を外した。
  - 実録音を足した：低音ドローンにディジュリドゥ、パイプオルガンのペダル、ティンパニのロール、ゴングの余韻、ピアノの最低音域、自然の低音（波の録音の低域）。打撃・脈動にフレームドラム、カホン、ダルブッカ、スリットドラム、コンガ。
  - 音高のある持続音は、和音の根音に合わせる（±6半音以内）。打撃は1〜4打のフレーズで鳴らす。
  - 新しい層の初期値：オルガンのペダル 20、ゴング 12、自然の低音 16、フレームドラム 12、スリットドラム 10。ほかは 0。

## 4. 未検証・既知の制限
- iPhone Safari 実機（下のバー・上の移動バー・持続音のつなぎ目）。
- ピアノ最低音域は1ファイル約4.5MB と大きい。最初に鳴る時の読み込みが遅れる場合がある（読み込みが1.5秒を過ぎたら、その回は鳴らさない）。
- VCSL の取得量は、事前の見積もり（20〜40MB）より多い約84MB だった（ピアノとゴングの原本が長いため）。アプリが読み込むのは FLAC 約26MB。
- 自律演奏の和音の変化は、持続音の次のつなぎ目（約8〜30秒後）に反映される。
