# saww audio ecosystem R&D レポート v0.58
**2026-11-07（チャット）／初期設定で鳴らす音を「ディジュリドゥ・低音・鳥」にする**

## 1. オーナー要望（2026-11-07 16:59）
- 「プリセットで鳴らすのはディジュリドゥと低音と鳥にする」

## 2. 変えたこと（初期設定＝最初に開いた時と「初期設定に戻す」）
| 部分 | v0.57 まで | v0.58 |
|---|---|---|
| 楽器・合成音の層（low・music・rhythm） | 16層（低音ドローン 31・オルガン持続音 46・擦弦 26・ペダル 20・ゴング 12・自然の低音 16・オルガン 38・ボウル 53・ピアノ 36・ベル 22・ハープ 28・心拍 22・キック 15・石 13・フレームドラム 12・スリットドラム 10） | **ディジュリドゥ（実録音）45・パイプオルガンのペダル（実録音）30 だけ**。ほかは 0 |
| 環境音 | 森の葉 26・高山の川 38 | すべて 0 |
| 生き物 | セミ2種（ミンミンゼミ系の cicada・ツクツクボウシ） | **鳥4種**：ウグイス（横浜）・ウタツグミ・ミソサザイ・ナイチンゲール（ロシア）。4種とも CC0（区分 A） |

- 「低音」は、無料版で鳴らせる実録音の **パイプオルガンのペダル** と読んだ。合成の「低音ドローン」や「自然の低音（波の実録音・低域）」に替えるのも、値を1つ変えるだけでできる。
- ディジュリドゥ・ペダルの2つは data/product_tiers.json の instruments.free に入っている。鳥4種は CC0。そのため、**無料版でも、商用モード「BY-SAを除く」「CC0のみ」でも、初期設定のまま全部鳴る**。
- 保存したプリセット・この端末に保存した設定は変えない。
- ブラウザでの確認：鳴るのは鳥4種だけ・実録音の持続音はディジュリドゥとペダル。生き物の声のピーク −38.8 dB、音楽チャンネル −30.4 dB。
