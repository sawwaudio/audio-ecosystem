## 1. 課題
- リールは canvas.captureStream と MediaRecorder で録画し、描画は requestAnimationFrame（rAF）で回していた。
- rAF はタブが裏に回ると止まるため、録画中に別のタブへ移ると、映像が固まったまま音だけが進むリールができた。

## 2. 変えたこと
- 録画中だけ Worker の時計を動かす（1/30 秒ごとに知らせる）。Worker の時計は裏のタブでも main の setInterval より間引かれにくい。
- 時計の知らせでは、タブが裏（document.hidden）か、rAF が 250 ミリ秒以上来ていない時だけ描く。表のタブでは二重に描かない。
- Worker が作れない環境は setInterval で代用（裏では1秒に1回程度に間引かれる）。
- 裏に回っていた時間を数え、0.5 秒以上なら書き出し後に案内を出す（「録画中にタブが裏に回っていました（約N秒）。その間も映像を描き続けましたが、端末によっては動きが少なくなります。仕上がりを確認してください。」）。英語表示にも対応。
- 書き出しで時計を止める。
