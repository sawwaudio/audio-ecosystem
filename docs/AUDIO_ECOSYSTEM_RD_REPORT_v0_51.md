## 2. 実装した機能
- 「合成音（シンセ）」の欄の先頭にチェック「合成音を鳴らさない（楽器は実録音だけ）」。既定は切（従来どおり）。
- 入れた時に止めるもの：groups の low・music・rhythm のうち実録音でないもの（低音ドローン・オルガン持続音・擦弦持続音・パイプオルガン・シンギングボウル・ソフトピアノ・柔らかなベル・心拍・ランダムキック・石の打撃）と、和音が変わる時の合成の響き。
- 止めないもの：楽器（実録音）、ハープ・ヴィブラフォン（実録音サンプル）、生き物・環境音の実録音、試聴の欄での1音ずつの確認。旧合成環境音（「旧合成音・抽象音を使う」）は別の切り替えのまま。
- つまみの値は変えない（切ると元どおり鳴る）。欄の見出しに「停止中」、欄の中に説明を出し、合成音のつまみを薄く表示。
- 保存はこの端末のブラウザ（localStorage `saww.synthOff`）だけ。プリセットには入れていない。
