## 2. 実装した機能
### 2-1. 相対エンコーダー（無限に回るつまみ・ジョグ）
- MIDI の割り当て一覧で、つまみ・フェーダー・スライダーに割り当てた CC の行に「動き方」の選択を出す（ピッチベンド・ノート・ボタンの行には出さない）。
- 方式：絶対値（既定・従来どおり）／相対（2の補数：1〜63 が＋、127 が −1）／相対（64が中央：65 が＋1、63 が −1）／相対（符号ビット：1〜63 が＋、65〜127 が −）。
- 1目盛りで範囲の 1/64 動く（ミキサーのフェーダー 0〜1 なら 1/64、スライダーは最低でも1刻み）。範囲の端で止まる。

### 2-2. ソフトテイクオーバー
- MIDI 欄のチェック「ソフトテイクオーバー（MIDI のつまみが画面の値を通るまで動かさない）」。既定は切（v0.46 と同じ動き）。
- 入れると、絶対値のつまみは「画面の値の ±3% 以内に来る」か「直前の値と今の値の間に画面の値がある（通り過ぎた）」まで値を変えない。その間は状態表示に「ソフトテイクオーバー：MIDI のつまみを画面の値（xx%）まで動かすと操作できます。」。
- 画面（マウス・キーボード・プリセット・ダブルタップの初期化など）で値が変わったら、MIDI のつまみは拾い直しになる（最後に MIDI で入れた値と画面の値が 1.5% 以上違う時）。
- 相対の割り当ては対象外（位置のずれが起きないため）。

### 2-3. 保存
- localStorage `ae-midi` は従来の `{v:1,maps}` に、既定でない時だけ `modes`（{'cc:ch:n': 'rel2c'|'relbin'|'relsign'}）と `soft:true` を足す。v0.46 の保存データはそのまま読める。
- 読み込み時に、不正な方式名、CC 以外（ピッチベンド・ノート）への方式、割り当てのない行の方式、真偽値でない soft は捨てる。
- 割り当ての削除・「割り当てをすべて消す」で方式も消える（ソフトテイクオーバーの設定は残す）。
- 外部へは送らない。音源・権利の扱いは変えていない（新しい音源なし）。

## 4. 未検証・既知の制限
- **実際の MIDI 機器での動作は未検証**。相対の方式は機器ごとに違うため、オーナーの機器で方式を選んで確かめる必要がある。
- 1目盛りの大きさ（範囲の 1/64）は固定。加速（速く回すと大きく動く）は機器側の設定に従う。
- MIDI の出力（機器のランプを点ける）は未対応。Safari は Web MIDI に対応していない。
