## 1. 何ができるようになったか
ミキサーの下に「サンプラー / SAMPLER」の欄を追加した（タッチ演奏は一番下のまま）。
| 手順 | 内容 |
|---|---|
| 録音を選ぶ | 自然録音127本＋楽器の実録音15本から選んで「読み込む」 |
| 区間を切り取る | 波形を指でなぞる（始点・終点のスライダー、キーボードの ←→ でも可。Shift＋←→ で終点だけ） |
| 鳴らし方 | 1回再生／ループ（もう一度押すと止まる）／押している間だけ鳴らす |
| 加工 | 逆再生、速度・音程（−12〜+12 半音。再生速度を変える）、フェード（2〜300ms）、拍に合わせて鳴らす（BEAT FX のテンポの次の拍で鳴り始める） |
| パッド | 8個（4列×2段）。「区間をパッドに割り当て」で割り当て先に入れ、次のパッドへ進む。押すと鳴る（指・マウス・Space/Enter） |
| その他 | 区間の試聴、すべて止める、割り当て先を空にする |

- 音はミキサーのサンプラーチャンネル（`mixLane('sampler')`）に入るので、M1 の EQ・フィルター・フェーダー・ミュート、M3 のチャンネルFX、M2 の BEAT FX（かける先＝サンプラー／マスター）がかかる。パッドを割り当てるとサンプラーのチャンネルの薄表示が消える。
- 1パッドあたり最大12秒（端末のメモリを守るため。8パッドで最大約 30〜40MB）。

## 2. 作り
- 切り取りはサンプル単位のコピー（`smpSlice`）。逆再生は反転コピー（`smpReversed`）を割り当て時に作っておく。元の録音のバッファーは LRU で解放されても、パッドは自分のコピーを持つので鳴り続ける。
- 1音は AudioBufferSource ＋ 音量の包絡（`smpVoice`）。1回再生は区間の終わりでフェードアウトして止まる。ループは区間全体を繰り返し、止める時は短いフェード。止める処理は `cancelAndHoldAtTime`（対応していない環境は現在値で保持）。
- 音量は環境層と同じ基準（実録音は台帳の performanceGain、楽器は読み込み時の補正値）。
- 権利：商用モードの対象外の録音は選択肢が無効になり、読み込めない。割り当て済みのパッドは薄く表示されて鳴らず、鳴っていた音はモードを切り替えた時点で止まる（`applyRights` から `samplerRightsChanged` を呼ぶ）。代用はしない。パッドを鳴らすと `noteRecUse` で記録するので、WAV 録音・リールのクレジットにその録音が入る（切り取り・加工は改変として既存の帰属表示の文面どおり）。
- 新しい音源は作らない。鳴るのは実録音の切り取りだけ。

## 3. 検証（build/test_sampler.js、すべて合格）
| 項目 | 結果 |
|---|---|
| 画面 | 欄がミキサーとタッチ演奏の間、パッド8個、選択肢 142（自然録音127＋楽器15） |
| 切り取り（オフライン・48kHz） | 0.25〜0.5秒 → 12000サンプル、元と誤差0。出力も区間と一致（1e-6 未満）、終わった後は無音 |
| 逆再生 | 区間を後ろから（誤差 1e-6 未満） |
| 速度・音程 | +12 で長さが半分（k 番目＝区間の 2k 番目）、−12 で2倍 |
| ループ | 0.25秒の区間を2周目もサンプル一致で繰り返し、離すとフェードして止まる |
| フェード 100ms | 50ms の時点でちょうど半分の音量 |
| 実演奏 | CC0 の録音（森の葉擦れ）を読み込み、波形をなぞって 20〜40% を選択、2秒をパッド1へ。押すとサンプラーチャンネルで鳴る、ミュートで無音、1回再生は区間の長さで終わる |
| 鳴らし方 | 押している間だけ（マウス・Space）、ループ（もう一度押すと止まる）、逆再生・音程がパッドの表示に出る、拍に合わせて（120BPM で 0.5秒の倍数で鳴り始める） |
| 帰属表示 | WAV 録音中にパッドを鳴らすと、その録音がクレジットの対象に入る |
| 商用モード | CC BY のアブラゼミを割り当て → 「CC0 のみ」で鳴っていたループが止まる・パッドは薄表示・押しても鳴らず理由を表示・選択肢が無効・読み込みも拒否。CC0 の録音は使える。「すべて」に戻すと鳴らせる |
| 楽器 | ハープの実録音も読み込める |
| 英語表示・画面幅・エラー | 未翻訳0、日本語への往復、390px で横はみ出しなし、エラー0 |
