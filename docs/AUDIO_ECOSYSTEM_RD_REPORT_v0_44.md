## 2. 実装した機能：設定をプリセットに保存
プリセット JSON（`format: audio-ecosystem-preset`、`schema: 1` のまま。項目の追加のみ）に次の3つを加えた。

| 項目 | 中身 | 保存しないもの |
|---|---|---|
| `mixer` | 4チャンネル（生き物・環境音・音楽・サンプラー）の TRIM・HI/MID/LOW・FILTER・FX・フェーダー・MUTE、チャンネルFXの種類 `cfx`、マスター EQ（`master`） | — |
| `beatFx` | 種類・拍の長さ・かける先・テンポ・ドライ／ウェット・効果ごとの専用つまみ10個（`params`） | オン／オフ・押している間（読み込んだ瞬間に効果が鳴り出さないため） |
| `sampler` | パッド8個：`src`（kind＝recording／instrument と id）・`start`・`end`（秒）・`mode`・`reverse`・`pitch`・`fade`・`quant` | 音声データ（読み込み時に元の録音から同じ区間を切り取り直す） |

- **権利**：サンプラーのパッドに使った自然録音も `rights.sources` に入る（区分・ライセンス・作者・出典・帰属表示の要否）。読み込み時、いまの商用モードで対象外の録音のパッドは読み込まず、件数を表示する（代用しない）。録音が見つからないパッドも同様。
- **検査**：不正な種類・型は何も変えずに拒否する（例「不正なミキサー設定: bio.trim」「不正なサンプラー設定: パッド1」）。数値の範囲外は丸める。項目のない旧プリセットは、いまの設定を変えない。
- **新しい音源は作らない**：パッドは実録音の切り取りの再現だけ。

## 4. 未検証・既知の制限
- iPhone・Mac Safari でのプリセットの書き出し・読み込み、パッドの録音の再読み込みにかかる時間。
- 旧版アプリで新形式のプリセットを読んだ時の挙動（追加項目は無視される想定）。
- 「復元」ボタン（localStorage）はミキサー等を扱わない。v0.43 のトラック・リール作成のテンプレートはプリセットに含めていない。
- 耳での確認は不要な変更（音の処理は変えていない）だが、読み込み後に既存の M1〜M4 の音がそのまま鳴ることは自動テストでのみ確認。
