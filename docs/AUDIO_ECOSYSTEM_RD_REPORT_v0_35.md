# AUDIO ECOSYSTEM R&D レポート v0.35 — DJ ミキサー（第1段階 M1）
**2026-11-02（チャット）／設計：docs/DJ_MIXER_SPEC.md**

## 1. 何ができるようになったか
画面の「ミキサー / MIXER」（タッチ演奏の上）に4つのチャンネルが付いた。
| チャンネル | 入る音 |
|---|---|
| 生き物 | 生き物の実録音、（実録音のない種の）合成の模倣音（v0.33 以降、自律演奏では鳴らない） |
| 環境音 | 環境層の実録音、旧合成の環境音、川・雪崩の低域 |
| 音楽 | ドローン（低音・オルガン・擦弦）、合成の楽器、実録音のハープ・ヴィブラフォン |
| サンプラー | 第4段階（切り取り・パッド）で使う。いまは無音 |

各チャンネルには、上から順に次の操作がある。
- TRIM：−9〜+9dB
- HI・MID・LOW：中央で 0dB、右いっぱいで +6dB、左いっぱいでキル（その帯域が消える）
- FILTER：左に回すとローパス（20kHz→90Hz）、右に回すとハイパス（20Hz→8kHz）、中央でオフ
- MUTE
- フェーダー：上が 0dB の2乗カーブ
- レベルメーター

マスターにはレベルメーター、リミッター、初期化ボタンがある。

## 2. 作り
- **3バンド・アイソレーター**
  - 4次のリンクウィッツ・ライリー型クロスオーバー（250Hz・3kHz）で3帯域に分けて足し戻す。
  - 低域の経路に 3kHz のオールパスを入れて位相を揃え、つまみが中央なら周波数特性が平らになるようにした（実測 ±0.25dB 以内）。
  - 棚型のイコライザーとは違い、キルで帯域がほぼ完全に消える。
- **レーン**
  - 1チャンネルにつき、行き先ごとに経路を3本持つ：dry（マスターへ）、wet（リバーブ送りへ）、direct（リミッターへ。楽器の経路）。
  - 3本すべてに同じ設定を反映する。そのため、EQ・フィルター・フェーダーはリバーブにかかる前の音にも効く。
  - レーンはチャンネルごとに必要な分だけ作り、いまは合計9本。
- **リミッター**
  - 既存のコンプレッサーとマスター音量の間に入れた（しきい値 −1dBFS・比20・アタック2ms）。
  - Web Audio のコンプレッサーは自動で約 +0.57dB 持ち上げるので、その分を下げて補正し、音量は変更前と同じにした。
  - WAV 録音とリールはマスター音量の後で録っているため、リミッターの効果も含まれる。
- **操作**
  - つまみは上下ドラッグで回し、ダブルタップで初期値に戻る。キーボード（矢印・Home/End・Delete）でも操作できる。
  - フェーダーは触った位置に動く。
  - 読み上げ用に役割（role="slider"）と値の説明を付けた。英語表示にも対応。

## 3. 検証（build/test_mixer.js、すべて合格）
| 項目 | 結果 |
|---|---|
| 初期状態の周波数特性（40Hz〜12kHz） | ±0.25dB 以内 |
| LOW キル（40Hz）／MID キル（1kHz）／HI キル（12kHz） | −50dB 以下／−30dB 以下／−35dB 以下。他の帯域への影響は 0.3dB 未満 |
| HI 最大（12kHz） | +6.0dB |
| フィルター ±0.6 | ローパスで 6kHz が −15dB 以下（100Hz はほぼそのまま）、ハイパスで 40Hz が −15dB 以下 |
| フェーダー半分／TRIM −6 | −12.04dB／−6.0dB |
| 実演奏中 | 環境音のミュート、音楽のフェーダー0で、そのチャンネルが無音になる |
| 操作・英語・画面幅 | キーボード・ドラッグ・初期化が正しく動く。未翻訳0、390px で横にはみ出さない、エラー0 |

既存のテスト（i18n・v024 の 126 ファイル照合・geo・rights・badges・preset_rights・attribution・beds・japan_beds・memory・reel・v033）もすべて合格した。リールの書き出し（5秒）も合格。
