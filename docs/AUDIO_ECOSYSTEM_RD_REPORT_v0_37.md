## 2. 「動き」の構成（下から順に重ねる）
1. **背景**：夜の水辺のような深い色のグラデーションと周辺減光。色相は音の明るさ（スペクトル重心）でゆっくり変わる（低い音が多いと青、高い音が多いと緑寄り）。
2. **立ちのぼる音の霧**：中央が低い音、外側が高い音の左右対称のスペクトル。下から上へ流れ、上に行くほど薄れる。
3. **光の粒**：ホタルのような光が110粒、ゆっくり上へ。高い音で明るくなり、中音で速くなる。音の立ち上がりで輪からはじける。
4. **声の輪**：周波数ごとの強さで輪郭が変わる（左右対称・ゆっくり回転）。低い音で輪が大きく息づく。内側に、いまの波形をなぞる細い輪（逆回転）。
5. **波紋**：音の立ち上がり（スペクトル変化の急増）で小さく、新しい声が鳴り始めた時に大きく広がる。
6. **文字**
   - 冒頭2.6秒：大きなタイトル「AUDIO ECOSYSTEM／実録音の自然音で、いま生まれる音楽」。少し大きい状態から落ち着き、その後は左上に小さく残る。
   - カード：鳴き始めた実録音の和名・英名・学名・録音地（原本の記載。分布ではない）・作者とライセンス。新しい順に2件。浮かび上がって、鳴り終わると消える。
   - 最下行：商用モードと「全クレジットは説明欄」。
   - 安全域：文字はすべて 1080×1920 のうち、上 220px・下 340px・右 148px を避けた範囲に置く（SNS の画面部品に隠れにくいように）。
- 音量に左右されないよう、反応はゆっくり下がる最大値で正規化している。音は変えない（絵だけ）。録音のない合成音の名前は出さない（従来どおり）。

## 3. 速度
- 最初の実装は、ヘッドレス Chromium（GPU なし）で約20fps だった。
- 原因を一つずつ外して測り、次の3つと特定した：文字の影のぼかし（毎フレーム）、霧の全画面の拡大描画、周辺減光の重ね描き。
- 対処：
  - 影付きの文字はブロックごとに1回だけ画像にして使い回す。
  - 背景と周辺減光は1枚に焼き込み、色相が3度以上変わった時だけ作り直す。
  - 霧は画面の下70%にだけ描き、小さい画像（40×128）の段階でグラデーションの型抜きをしてから拡大する。
- 結果：約60fps（「分析」と同等）。
- あわせて、薄い霧が帯状に残る不具合も直した。1行ずつ透明度を下げる方式では、8bit の丸めで薄い霧が消えきらなかった。型抜き方式にしたことで解消した。

## 4. 検証
- build/test_reel_motion.js：すべて合格。確かめた項目は次のとおり。
  - 既定が「動き」であること。
  - 無音でもプレビューが動き、演奏中はより大きく動くこと（縮小画像のフレーム差：無音 0.22 → 演奏中 6.5）。
  - 音に反応すること。カードがいま鳴っている実録音を網羅し、鳴き始めに強い波紋が出ること。
  - 文字がすべて安全域内にあること。描画は平均 約0.7ms（JS 側のみ）。
  - 「分析」に切り替えられ、「動き」で録画でき、開始時に見た目を指定できること。
  - 英語表示、横はみ出しなし、エラー0。
- 既存テスト：すべて合格（test_parity は従来どおり、比較側の旧ファイルがなく実行不可）。
- build/render_reel.js：8秒、既定の「動き」で合格（H.264 1080×1920 30fps、AAC 48kHz ステレオ、音声あり）。`--style analysis` で従来の見た目も選べる。
