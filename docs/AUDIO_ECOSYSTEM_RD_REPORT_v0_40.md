## 2. 作り
- 専用つまみは差し込み済みのエフェクトに直接反映する（作り直さないので音が途切れない）。帰還量・深さ・Q は AudioParam をなめらかに動かす。リバーブは残響の表を作り直す。
- **トランスゲートの作り直し**：割合を変えるたびに開閉の表を作り直すと再生位置がずれるため、1周期分の cos と sin の表を同じ速さで繰り返し再生し、
  cos(2π(u−d/2)) ＝ cos(2πu)·cos(πd) ＋ sin(2πu)·sin(πd)（u＝刻みの中の位置、d＝開いている割合）
  を2つのゲインで作り、しきい値 cos(πd) を超えた所だけ開く（WaveShaper）。割合を変える時はゲイン2つと WaveShaper の表だけを変える。cos・sin は表の継ぎ目で連続なので、のこぎり波のような継ぎ目の乱れがない。縁の傾斜（約0.6%）は開いている側に置く。
- **ビットクラッシュのビット数**：WaveShaper の階段状の表を差し替える。表の点は1段あたり128点（6ビットで v0.39 と同じ8193点）。
- 新しい音源は作らない（制御信号と表の差し替えだけ）。

## 3. 検証（build/test_fx.js、すべて合格）
| 項目 | 結果 |
|---|---|
| 10種のオン／オフ | オンで原音との差 0.17〜1.29、オフ（差し込んだだけ）は原音とサンプル単位で一致 |
| ディレイ 20% | 2回目の繰り返し 0.200 |
| トランスゲート 25%／75% | 120BPM・1/2拍で、25% は 0.0625秒鳴って残りは無音（RMS 0.348／0）、75% は最後の 1/4 だけ無音 |
| ビットクラッシュ 3ビット | 98% の値が 1/4 刻みの段に乗る |
| リバーブ ×4 | 残響が1秒続き、1.05秒以降は 2e-3 未満 |
| ロール 50% | 1周ごとにちょうど半分（誤差0） |
| フィードバック最大 | ディレイ・エコー・ピンポン 62%、フランジャー深さ100%：ノイズ3秒の後半のピークが前半の2倍未満（発散しない） |
| 画面 | ボタンで選択、つまみの名前・上限が効果ごとに変わる、値を効果ごとに覚える、上限で止まる、英語表示（未翻訳0）、390px で横はみ出しなし |
| 実演奏 | 10種それぞれ専用つまみを最大にしてもエラー0、マスターのピーク −26〜−31dBFS |

既存テスト（attribution・badges・beds_v028・geo・i18n・japan_beds・library_v038・memory・mixer・preset_rights・reel・reel_motion・rights・v024・v033）もすべて合格。test_parity は従来どおり比較側の v0.23 旧ファイルがなく実行不可。
