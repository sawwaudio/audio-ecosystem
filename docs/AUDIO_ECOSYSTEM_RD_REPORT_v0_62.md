## 1. 実装したこと
- BEAT FX の「テンポ（BPM）・TAP」の下にチェック「自律演奏の楽器を拍に合わせる」（既定は切＝従来どおり）。
- 入れると、自律演奏で鳴る実録音の楽器（打楽器・旋律・ときどき鳴らす音）のフレーズの最初の音を、BEAT FX のテンポの次の8分の拍へ遅らせる（最大で8分1つ分）。
  - 格子は音声の時刻0からの 60/BPM/2 秒刻みで、サンプラーの「拍に合わせて鳴らす」と同じ基準。
  - フレーズ内の音の間隔はもともと BEAT FX のテンポの8分の整数倍なので、フレーズ全体が拍に乗る。
  - 手で鳴らした音（タップ・試聴）は遅らせない。持続音（ディジュリドゥ・オルガンのペダルなど）・合成音の層・生き物の声は変えない。
- プリセット：beatFx に `grid`（真偽値）を書き、読み込みで戻す。真偽値以外は「不正なエフェクト設定: grid」で拒否。古いプリセット（grid なし）はそのまま読める。
- 英語表示「Lock the autonomous instruments to the beat」を index.html と build/src_i18n.js の両方に追加（完全一致）。
- build/src_studio.js と index.html の ae-studio 区間に同じ変更。テスト用に `__realDebug.starts()`（鳴っている楽器の開始時刻）・`__realDebug.snap(時刻, 手で鳴らしたか)`。
