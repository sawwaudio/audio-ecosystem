## 2. 特定商取引法に基づく表記・定期購入の表示
| 部分 | 内容 |
|---|---|
| data/legal.json | 表記の元データ。オーナーが決める項目は null（記入待ち）。 |
| legal.html（build/make_legal.py が作る） | 公開ページ「特定商取引法に基づく表記」。必須項目を1ページにまとめる（Stripe の要件）。 |
| アプリ・プランの欄 | legal.html へのリンク。販売前は、定期購入の内容の案を畳んで出す。 |
| アプリ・購入ボタンの前（販売中） | 「お申し込みの前に（定期購入の内容）」を出し、確認のチェックを置く。チェックを入れるまで購入ボタンは押せない（押すと確認欄へ案内）。 |
| 課金の開始の条件 | 記入待ちの項目が残る間は、checkout.status が live でも課金を始めない。 |
| 料金のカード | legal.json に月額を入れると「¥… / 月（税込）」を出す。 |

- **legal.html の項目**
  - 販売事業者・屋号・運営統括責任者・所在地・電話番号・メールアドレス
  - 販売価格（1年間の目安も）・商品代金以外の必要料金
  - 支払いの方法・支払いの時期・提供の時期
  - 定期購入の契約期間と自動更新・解約の方法・返品と返金・申込みの撤回
  - 販売数量と申込期間・動作環境
- **購入前の確認欄の項目**：定期購入の最終確認で示す事項（消費者庁の申込み段階の表示のガイドライン）に、動作環境を足した。
  - 内容・価格・契約期間と自動更新
  - 支払いの時期と方法・提供の時期
  - 解約の方法・返品と返金・動作環境
- **英語表示の扱い**：本文は日本の法律に基づく表示なので日本語のまま（翻訳から外す）。英語表示では「Shown in Japanese as required by Japanese law.」を足す。
- **方針の案（オーナーの確認が必要）**
  - 返金はしない（二重請求など当方の誤りは返金）。
  - 解約しても、支払い済みの期間の終わりまで PRO を使える。
  - 支払日は、毎月お申し込みの日と同じ日（Stripe の既定）。
- **Stripe でオーナーがすること**（server/README.md の5）
  1. 「特定商取引法に基づく表記」の URL を登録する。
  2. 支払いリンクのカスタムテキストに、自動更新と解約の方法を書く。
  3. 顧客ポータルの解約を「請求期間の終了時」にする。

## 3. 生き物と環境音のイメージ写真
- 種を特定できない生き物の録音と環境音に、雰囲気の合う実写を「イメージ」として付けた（data/scene_photos.json → ae-scenes）。
  - 実写は 17 枚で、録音 58 本に付く。
  - 環境音：30 本のうち 27 本。
  - 生き物：両生類 16・鳥 8（キツツキ・夜明けの合唱など）・哺乳類 4（コウモリ・キツネ）・水の生き物 2（シャチ・イルカ）・虫 1。
- 種が特定できる録音は、従来どおり学名で一致した写真（data/species_photos.json）が優先。イメージ写真は、学名の写真がない録音にだけ付く。
- **誤解を避ける表示**：イメージ写真は録音の場所・個体・種そのものではない。そのため次のように明記する。
  - タイル：左上に「イメージ」の印。
  - 詳細シート：「イメージ写真（録音の場所・生き物そのものではありません）：撮影地・作者・ライセンス」。
  - リール：映像の出典に「MOOD PHOTO」。
- **写真の条件**：Wikimedia Commons の CC0・パブリックドメイン（米国の国立公園局・魚類野生生物局・海洋大気庁・森林局・NASA の職務著作）・CC BY 2.0 だけ。各ファイルのページで、2026-11-07 にライセンスと作者を確認した。
  - CC BY-SA の写真（竹林・アビなど多い）は使っていない。
  - 人の写る写真は避けた。ただし、たき火の写真は国立公園局の説明写真。
- **まだ写真のないもの（31本）**：これまでどおりの絵。次の段階で探す。
  - セミ・コオロギ類 11
  - ナイチンゲール 2・アビ 3・コノハズク 1・ホエザル・ティティ
  - ゾウ・アシカ 2・アマゾンカワイルカ・テッポウエビ
  - 水中マイクの池 3・アマゾンの夜・アイスランドの森・雪浦の竹林
- この環境のシェルからは Commons に届かないため、写真の確認は Web 検索と Commons の写しのページで行った。画像はアプリが表示の時に Commons から直接読み込む（従来と同じ）。
