## 1. この版で変わったこと
| 項目 | 内容 | 状態 |
|---|---|---|
| プリセット書き出し | `rightsMode`（いまの商用モード）と `rights` を追加。`rights.sources` は参加中の生き物（実録音あり）と音量が0より大きい環境層の一覧で、各素材の区分（A/B/C/X、利用者の音声は U）・ライセンス・ライセンスURL・作品名・作者・出典URL・帰属表示の要否（`attributionRequired`）・いまのモードで鳴るか（`playsInMode`）を持つ。`rights.tiers` に区分ごとの件数、`rights.notice` に日英の注意書き | 実装・自動テスト合格 |
| 書き出し時の表示 | 「プリセットJSONを書き出しました。 ライセンス区分と帰属情報を含みます（A n件・B n件・C n件）。」 | 自動テスト合格 |
| プリセット読み込み | プリセットの商用モードが**いまの設定と同じか厳しい時だけ**適用する（すべて＜BY-SAを除く＜CC0のみ）。緩いモードのプリセットを読み込んでも BY-SA が鳴り出すことはなく、「いまの設定のままにしました」と表示。プリセットの素材のうち対象外の件数も表示（代用しない） | 自動テスト合格 |
| 検証 | `rightsMode` が不明な値ならプリセット全体を読み込まない（「不正な商用モード」）。`rightsMode` のない旧プリセットは従来どおり読み込め、モードは変わらない | 自動テスト合格 |
| 形式 | `schema` は 1 のまま（項目の追加のみ）。旧版のアプリは追加項目を無視する（コード上の確認。旧版での実読み込みは未検証） | — |
| 英語表示 | 新しい文言4種（規則）と「不正な商用モード」を `build/src_i18n.js` と index.html の辞書の両方に追加 | 自動テスト合格（未翻訳0） |

帰属情報は録音台帳（`ae-recordings`）から取り、書き出しの帰属表示（v0.25）と同じ `attributionEntries` を使う。ブラウザ内保存（「保存」ボタン）にも同じ項目が入る。

## 3. 未検証・既知の課題
- 実機（iPhone・Mac Safari）でのプリセットの書き出し・読み込み。
