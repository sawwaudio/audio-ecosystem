## 1. 音源形式監査（Action 1 完了）

### 1.1 v0.23 で判明した事実

v0.23 の HTML を全展開して検証した結果、レポートv0.23の記述と実装に次の差異があった。

1. **演奏エンジンは原本を使っていなかった。** 自律演奏・環境層・試聴のすべてが `preview-*`（44.1kHz/モノラル/128kbps MP3）をデコードしていた。内蔵されていた Ogg 原本23本は一度も再生されていなかった。
2. **ステレオ原本をモノラル化していた。** 自然録音13本と楽器15本はステレオ原本だが、再生はモノラルMP3だった（原則2.2違反）。
3. **新規9録音の原本はHTMLに無かった。** `changes` には「原本保存」とあるが、HTMLに入っているのはモノラルMP3のみ（`asset-*` と `preview-*` が同一バイト列）。Commons 原本は Ogg Vorbis（7本ステレオ、スズメは96kHz）。
4. **forest-leaves の原典は真の非圧縮マスター**（96kHz / 32-bit / ステレオ / 158秒 / 121MB WAV）。HTML内は冒頭18秒を44.1kHz/16-bitに変換したFLAC。原典全長はこの環境に無い。
5. 低サンプルレート原典：ホトトギス 7812Hz、ウグイス・ミンミンゼミ 11024Hz、秋の虫2本 16kHz。互換MP3は44.1kHzに補間されているが情報は増えていない。

### 1.2 47サンプルの分類

| A1 | 15 | 非圧縮マスター入手済み（VCSL楽器15本） |

## 2. PCM WAV 再生経路（Action 2 実装）

### 2.1 PCM の作り方（原本優先・MP3からは作らない）

| 原本 | PCM | 説明 |
|---|---|---|
| VCSL WAV（15） | 原本ファイルそのもの | 固定コミット `c1ea7bcc…` から再取得。SHA-256 が台帳と一致 |
| FLAC（forest-leaves） | 16-bit WAV | 原本と同じビット深度。ビット完全一致を検証（差0） |
| Ogg Vorbis / Opus（22） | 24-bit WAV、原本サンプルレート・チャンネル数 | **原本を復号したもの。原本と同じ情報量で、非圧縮マスターではない**。互換MP3が持つ二重の非可逆圧縮とモノラル化を避けられる |
| MP3のみ（9） | 作らない | MP3→WAV は音質改善にならないため互換MP3で再生 |

- 復号ピークが0dBFSを超えた4本（barking-treefrog 1.011、field-cricket-europe 1.094、autumn-insects 1.002、autumn-insects-2 1.039）は、係数（0.914〜0.998）を掛けて24-bitに格納し、同じ係数を再生ゲインで打ち消す。クリップは発生しない。
- 15MBを超える2本（higurashi、forest-wind）は2分割し、アプリ内でdataチャンクを連結してから一度だけデコードする。分割境界にリサンプルの継ぎ目は出ない。

### 2.2 再生の切替

- 「再生に使う音源」：PCM WAV（既定）／原本ファイル／互換MP3。localStorageに記憶。
- フォールバック：PCM → 互換MP3、原本 → PCM → 互換MP3。代替した場合は画面に表示する。
- 音量：各録音の再生ゲインを、v0.23 の互換MP3（センター定位モノラル）と同じ出力レベルになるよう実測で合わせた。ミックスバランスはv0.23と変わらず、音源の違いだけで比較できる。
- 試聴（`<audio>`）もWAVを直接再生する。クリック内で `play()` を呼ぶ v0.23 の設計は維持した。分割ファイルの試聴は2本目へ連続再生する（試聴のみ境界にごく短い切れ目の可能性あり。演奏エンジンでは発生しない）。

### 2.3 アーキテクチャ（Action 3 実装）

```
index.html                     アプリ本体（メタデータJSONを内蔵、音源なし）
data/audio_manifest.json       音源ごとの pcm / original / compat：パス・SHA-256・形式・ゲイン・分割
data/recording_licenses.json   v0.23台帳を継承
data/wildlife_meta.json        分布・録音地・生息環境・音の性格（32録音）
data/wildlife_master_db.json   52対象DB（CSV同梱）
data/source_audit.json / .csv  47サンプル監査
audio/pcm/*.wav                25ファイル（23録音、141.7MB）
audio/original/*               原本 23本（11.9MB）
audio/compat/*.mp3             互換 32本（14.5MB）
instruments/pcm/*.wav          VCSL原本 15本（27.1MB）
instruments/compat/*.mp3       互換 15本（2.5MB）
```

- 必要時ロード：音源は鳴らす直前に1本ずつ取得・デコードする。
- 統合LRU：自然録音と楽器のデコード済みPCMを同じ128MiB枠で管理。再生中・読込中・固定中は解放しない。解放された楽器は次の発音時に再ロードする。
- ハープの起動待ちは最大6秒。以降はバックグラウンドで読み込む（v0.23は全数ロードまで開始しなかった）。
- 制約：音源を別ファイルから読むため `file://` で開くと音源が読めない（画面に案内を表示）。オフライン単体利用には v0.23 単一HTMLを引き続き残す。
- メモリ：デコード後のサイズはファイル形式に関係なくチャンネル数で決まる。ステレオ原本の復帰により、ステレオ録音のメモリ使用量はv0.23の2倍。

## 3. 地域・生息環境フィルター（指示書 §3〜§6 の一部を実装）

### 3.1 メタデータ（既存32録音）

各録音に、和名・英名・学名、自然分布地域、日本に自然分布するか、日本固有種か、録音国・地域、録音環境、野外/飼育、生息環境、鳴く時間帯、音の性格を登録した。

- **分布と録音地は別のフィールド。** 一方から他方を推定しない。
- `japanNative` / `japanEndemic` は `true / false / null(未確認)`。**null は日本産として扱わない。**
- 出典で確認した例：カジカガエルの日本固有（Wikipedia）。*Tettigonia cantans*・*Chorthippus brunneus* は出典に日本の記載がないため null。*C. biguttulus* は「日本を含む」との記載があるが、日本産を別種とする見解があるため null。
- その他の分布は一般的な分類知識による登録で、**出典URLは未記録（要確認）**。`distributionBasis` に明記した。
- 鳴く時間帯は種の一般的な生態に基づく。録音時刻ではない。
- 音の性格は鳴き方による手動分類。自動音響分析値（スペクトル平坦度・調性・包絡変動・パルス周期）を併記した。自動分類だけでは環境音の低域成分で誤判定するため、採用値にはしていない。

### 3.2 フィルターの判定規則

| 地域 | 判定 |
|---|---|
| All World | 全録音 |
| Japan — Japan Native Species | `japanNative === true` |
| Japan — Recorded in Japan | 録音地が日本 |
| Japan — Japan Endemic | `japanEndemic === true` |
| Asia / Europe / Africa / N. America / S. America / Oceania | 「自然分布する種」または「その地域で録音」を選択 |
| Ocean / Marine | 海洋性の種、または生息環境が海洋・海岸の録音 |

- 環境音（川・風・雨など）には分布がないため、録音地のみで判定する。録音地不明の環境音は All World と Ocean/Marine 以外に出ない。
- 生息環境9区分（Night Forest＝森林×夜）、時間帯（Day / Dusk / Night）、音の性格8区分を掛け合わせる。
- 地域を選ぶと、自律演奏の生物プールと環境層が同時に切り替わる。
- **該当がない場合は代用しない。** 生物層・環境層を止め、「該当する実録音がありません」と表示する。合成の旧環境音にも切り替えない。

### 3.3 判定結果（Chromiumで確認）

| 条件 | 件数 | 内容 |
|---|---|---|
| Japan Native Species | 14 | 日本録音10＋カジカガエル（録音地不明）＋トノサマバッタ・スズメ・ツバメ（海外録音） |
| Recorded in Japan | 10 | |
| Japan Endemic | 1 | カジカガエル |
| Japan × Temperate Forest × Night | 1 | ホトトギス |
| Europe（録音地） | 3 | Esk川・松林の強風・スズメ（ロシア） |
| Oceania（録音地） | 0 | 無音（代用なし） |

「Recorded in Japan」で25秒間自律演奏した間、条件外の音は0件。

**判明した課題：日本で録音された環境音（川・森・雨・海）が1本もない。** Japanモードでは環境層が鳴らない。日本録音の環境音は最優先の収集対象。

## 5. v0.24 の検証実績

- 3つの音源モードの切替と、それぞれのデコード（rocky-beach：MP3 → Opus原本 → 24-bit PCM）
- `<audio>` でのWAV試聴（playing・再生時間進行・エラーなし）
- 自律演奏の開始、WAV録音（AudioWorklet）の動作
- 地域フィルター13条件の判定、条件外の音が鳴らないこと
- 390px幅で横はみ出しなし（監査表・DB表は枠内スクロール）
- v0.23とのパリティ：25レイヤー、8音色、25試聴、32録音ボタン、harp/vibes発音

**未検証事項**

playing状態やcurrentTimeの進行は、物理的な音声出力を保証しない。

## 6. 既知の課題

1. **実録音ライブラリの「▶」ボタン**：自律演奏中に押すと、未選択の生物は即座にフェードされる。v0.23でも同じ挙動で、v0.24での回帰ではない。原因は未調査。
2. **公開版（claude.aiアーティファクト）の制約**：FLAC形式は配信できないため forest-leaves の原本FLACは除外（同一内容のPCM WAVで代替される）。また、ページからのファイル保存が許可されないため、WAV録音・プリセット・CSVの書き出しボタンは公開版では動かない。ローカル版では動く。
3. 試聴（`<audio>`）の音量はファイルそのままで、演奏エンジンのようなレベル合わせはしていない。iPhoneでは `audio.volume` が効かない。
4. 日本録音の環境音がゼロ（3.3）。
5. 新規9録音（C1）の Ogg 原典と、forest-leaves の96kHz原典全長が未保持。

## 8. Claudeへの引き継ぎ原則（v0.23から継承・追記）

1. 開発正本は v0.24 パッケージ（`index.html` ＋ `data/` ＋ `audio/` ＋ `instruments/`）。v0.23 単一HTMLはオフライン用として残す。音源は `build_assets.py` で v0.23 HTML と VCSL から再生成できる。
2. 本書は仕様と開発履歴であり、実行コードの代替ではない。
3. 既存25レイヤー、32自然録音、8楽器音色、15実楽器サンプルの機能を維持する。
4. 実装済み機能と将来計画、確認済み候補と取得済み音源を混同しない。
5. 原本優先。MP3からのWAV変換を高音質化とみなさない。原本復号PCMは「原本と同等」と記し、「非圧縮マスター」と書かない。
6. 分布と録音地を混同しない。未確認の分布を日本産と判定しない。
7. 該当音源がない地域・条件で、他地域の録音や合成音を代用しない。
8. CC BY-NC、権利保留、再配布不可の音源は採用しない。
9. 実装後は変更差分とテスト結果を本書に反映する。

**最終開発原則：既存の動作資産を保持しながら、実録音の品質・再生安定性・地域と生態系の正確さを段階的に高める。**
