## 2. テスト
- 新規 `build/test_reel_nature_v048.js`：ALL PASS。確認した項目は次のとおり。
  - 既定が「自然」。書体（明朝・ゴシック）。
  - 分類：127件、環境音30、生き物の分類ごとの件数。絞り込みの並び。環境音の欄に環境音だけ。水の生き物の絞り込み。全件に根拠があること。
  - 写真が主役であることと、写真から色を取ること。描画の速さ。音で絵が動くこと。
  - 「自然・紙」の地の色。画面の配色。
  - 「自然」での録画と、写真のクレジット。
  - 英語表示（未翻訳0）、はみ出しなし、エラー0。
- 既存24本もすべて合格。
  - 期待値を変えたもの：
    - test_ui_v045：生き物は97、環境音は30を別の欄に。
    - test_studio_v043：環境の録音のタイルの探し方。
    - test_reel_pop_v047：既定ではなくなったので、選んでから確かめる。配色の期待値。
    - test_reel_motion：選択肢の並び。
  - リール系は単独実行で合格。並列実行では、録画のフレーム数が負荷で足りないことがある（従来どおり）。
