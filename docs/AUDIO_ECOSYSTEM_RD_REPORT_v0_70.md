## 1. 既存の音響エンジンの調査（変更対象）

| `chords` / `CHORD_SETS` / `applyKey()`（v0.67） | 和音6つ・12キー×長短。根音（MIDI）と構成音（半音） | 変更なし（音律エンジンが根音と主音を参照） |

| `randomPitch()` | 自律演奏の旋律系の合成音（flute・organ・harmonics など）の音高 | 同上 |
| `harmonyChange()` | 和音の変わり目のボウル | 同上 |
| `touchNote()` | タッチ演奏の合成音と表示 | 同上（表示も実周波数） |
| `trigger()` の harp・vibes、`realLayerHit()` の melody | 楽器サンプル（実録音）を `playbackRate=2^(半音/12)` で鳴らす | **半音単位のまま**（`sampleMidi()` で最も近い半音に。録音の音程・速度を純正律や 432Hz に合わせて変えない） |

## 2. 変えたこと
- 音律エンジン：**基準周波数**（`tuning.ref`、A4、400〜480Hz）と**音律**（`tuning.system`：`ji5`＝5-limit 純正律の整数比の表／`12tet`＝12平均律）を別々のパラメーターで持つ。
  - 5-limit の比（主音から）：1/1・16/15・9/8・6/5・5/4・4/3・45/32・3/2・8/5・5/3・9/5・15/8。
  - 主音＝基準×2^((主音−A4)/12)（キー A なら A4 がちょうど基準の値）。和音の根音＝主音×音階の比、構成音＝根音×音程の比。**和音の中はすべて整数比**（例：Cmaj9＝1：5/4：3/2：15/8：9/4）。根音が音階上で変わると、その和音ごとに純正の響きになる（固定音階の「ウルフ」を避ける方式）。
  - 12平均律＋440Hz は従来の式と完全に同じ値（誤差0）。432Hz の平均律、440Hz の純正律なども選べる。
- 既定：新しく鳴らす合成音は **A4＝432Hz・5-limit 純正律**。選択は端末に記憶（`saww.tuning`）。
- 画面（演奏する → キーの下）：「基準 A4」（432／440／442 Hz）と「音律」（5-limit 純正律／12平均律）、いまの和音の**各音の実周波数**（例：`A4 = 432 Hz · C3 128.43 · E3 160.54 · G3 192.65 · B3 240.81 · D4 288.98 Hz`）。演奏中に切り替えると持続音を作り直す（クロスフェード）。
- プリセット：書き出しに `tuning`。読み込みで指定が無ければ 440Hz・12平均律（旧作品はそのまま同じ音高で鳴る）。範囲外・未知の音律は「不正な音律設定」で拒否。
- 英語：「Reference A4」「Tuning」「5-limit just intonation」「12-tone equal temperament」（build/src_i18n.js と index.html の辞書に同じ行）。

## 4. 未検証
- 実機・耳での確認（純正律のうなりの少なさ、432Hz の聴感）。
- **楽器サンプル（実録音・ほぼ 440Hz・平均律で録音）と合成音の音程差**：432Hz では約 −31.8 セント、純正律ではさらに和音の各音が平均律から −15.6〜+21.5 セントずれる（今回の和音の並びで計算）。依頼 9（録音素材を無断で変えない）に従い楽器サンプルは変えていないため、両方を重ねると音程が合わない可能性がある（オーナー判断の材料）。
- 依頼 7・8（Ambient・Experimental・Hybrid、YouTube Generative Radio との接続）：接続先のコードが無く未実装。
- WAV・リールの書き出しのクレジットへの音律の記載は未対応（プリセットのみ）。

## 5. オーナー判断の材料
- 楽器サンプルを基準・純正律に合わせる「同意付きの切り替え」（再生速度を数十セント変える）を足すか。足す場合も既定はオフにする案。
- 7 リミット（7/4 など）や他の音律（ピタゴラス・ミーントーン）の追加。今回は 5-limit のみ。
- 自然録音の環境層との兼ね合い（音程を持たないため変更不要と判断）。
