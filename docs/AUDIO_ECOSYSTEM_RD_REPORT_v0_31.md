## 2. 書き出し形式についての注意（重要）
- テスト環境（Playwright の Chromium ヘッドレス）では `video/mp4` が選ばれたが、中身は **VP9／Opus の MP4** だった（ffprobe で確認。H.264/AAC はこの Chromium では使えない）。
- Instagram リールに確実に載せるには H.264/AAC が望ましい。通常版の Chrome・Safari で H.264/AAC の MP4 になるかは**未検証**。ならない場合は、フェーズ1の「自動レンダリング」（クラウドで ffmpeg により H.264/AAC へ変換）か、利用者側での変換が必要。
