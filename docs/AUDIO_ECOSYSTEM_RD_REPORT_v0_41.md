## 1. 何ができるようになったか
各チャンネル（生き物・環境音・音楽・サンプラー）に「FX」つまみが付いた。中央でオフ、左右に回すほど強くなる。種類はミキサー欄の「CHANNEL FX / チャンネルFX」のボタン4つから選ぶ（全チャンネル共通）。
| 種類 | 左に回す | 右に回す | 中央に戻した時 |
|---|---|---|---|
| リバーブ | 短い残響（0.8秒） | 長い残響（3秒） | 余韻が自然に消える |
| ダブエコー | 1/2拍ごとの繰り返し | 3/4拍ごとの繰り返し | 余韻が自然に消える |
| スイープ | 低い帯域だけを通す（いっぱいで約60Hz） | 高い帯域だけを通す（約16kHz） | すぐ元の音 |
| クラッシュ | 音を粗く（左右同じ） | 同左 | すぐ元の音 |

- 量：リバーブ・ダブエコーは送りの量、スイープ・クラッシュは原音との入れ替えの割合。ダブエコーの帰還は 30〜62%（量とともに増える）、クラッシュのビット数は 8→3。
- テンポは BEAT FX（M2）と共通（手入力・TAP）。BEAT FX と同時に使える。

## 2. 作り
- 位置：設計書の図のとおり、各チャンネルの「フィルターの後・フェーダーの前」。チャンネルの dry・wet・direct の全レーンに同じ設定を反映する（M1 と同じ考え方）。
- つまみを最初に中央から動かした時に、そのレーンにだけ作って差し込む。触らないチャンネルは v0.40 と同じ経路（テストで出力が一致）。種類を切り替えると作り直す。
- 部品は M2 の makeFx を流用（リバーブ＝計算で作る残響、ダブエコー＝ループ内で暗くなるエコー、クラッシュ＝サンプル保持＋ビット落とし）。スイープはバンドパスフィルター。新しい音源は作らない。
- 中央の ±4% はオフ（フィルターと同じ）。

## 3. 検証（build/test_mixer_cfx.js、すべて合格）
| 項目 | 結果 |
|---|---|
| 中央（既定） | FX を作らず、出力は M1 のレーンと一致 |
| 4種×左右 | 出力が変わる（FX なしとの差 0.14〜1.31） |
| 中央に戻す | スイープ・クラッシュは直後から一致、リバーブ・ダブエコーは余韻が消える |
| リバーブの左右 | 残響が 1e-3 を下回るまで：左 0.73秒／右 2.32秒 |
| ダブエコーの左右（120BPM） | 左 0.25秒・右 0.375秒ごと。1回目の大きさ＝つまみの量（0.792） |
| スイープの左右（いっぱい） | 高域の割合 0.0012（左）／2.94（右）、FX なしは 2.00 |
| クラッシュ（いっぱい） | 1/4 刻みの段 100%、6サンプル保持 100%、左右で同じ |
| 発散しない | ダブエコーいっぱい：ノイズ3秒の後半のピークが前半の2倍未満 |
| 実演奏 | 4種それぞれ環境音のレーンにだけ差し込み、マスターのピーク −25〜−29dBFS。3チャンネルを左いっぱいでも 0dBFS 以下。BPM 100 でダブエコーの間隔 0.3秒に追従。BEAT FX と同時に使える |
| 操作・表示 | キーボード（Home・Delete）、初期化、英語表示（未翻訳0）、390px で横はみ出しなし、エラー0 |
