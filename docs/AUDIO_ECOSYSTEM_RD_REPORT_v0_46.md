## 2. 実装した機能：MIDI 機器から操作する
- 場所：ミキサー欄の BEAT FX の後に「MIDI / コントローラ」。ボタンは「MIDI 機器に接続」「割り当てを学習」「割り当てをすべて消す」、状態表示、最後に受けた入力、割り当ての一覧（1件ずつ ✕ で削除）。
- 接続：`navigator.requestMIDIAccess({sysex:false})`。SysEx は要求しない。機器のつなぎ直し（statechange）で入力を付け直す。Web MIDI のないブラウザでは「このブラウザは Web MIDI に対応していません。」と表示する。
- 学習：「割り当てを学習」→ 画面の操作部を押す（この押下は操作として働かない）→ MIDI 機器のつまみ・フェーダー・パッドを動かす。Esc か同じボタンで終了。同じ操作部への古い割り当ては置き換える。割り当てられない操作部（波形など）はその旨を表示する。
- 割り当てられる操作部：4チャンネルの TRIM・HI・MID・LOW・FILTER・FX・フェーダー・MUTE、マスター EQ、チャンネルFXの種類、BEAT FX（効果10種・拍の長さ・オン／オフ・押している間だけ・ドライ／ウェット・専用つまみ・TAP など）、サンプラー（パッド8個・始点／終点・音程・フェードのスライダー・各ボタン）、自律演奏の開始ボタン。
- メッセージの扱い：CC とピッチベンド（14ビット）は連続値として操作部の範囲に割り付ける。つまみ・フェーダーにノートは割り当てない（CC を求める）。ノートはボタン・パッドの押す／離す（ベロシティ0のノートオンは離す扱い）。ボタンに CC を割り当てた場合は 64 以上に上がった時だけ押す。
- 保存：割り当てはこの端末のブラウザ（localStorage `ae-midi`）にだけ保存し、外部へ送らない。読み込み時に形式を検査し、不正な行は捨てる。プリセット JSON には入れていない（機器ごとに違うため）。
- 権利：パッドは既存の `smpTrigger` を通るので、商用モードの対象外の録音は MIDI からも鳴らない。新しい音源は作らない。

## 4. 未検証・既知の制限
- **実際の MIDI 機器での動作は未検証**（テストは requestMIDIAccess を差し替えた模擬機器）。Chrome の許可ダイアログ、USB 機器の抜き差し、複数機器の同時接続。
- 相対値を送るエンコーダー（ジョグ・無限回転つまみ）には未対応（絶対値の CC として扱う）。ソフトテイクオーバー（つまみの位置が画面とずれている時の飛び）も未対応。
- MIDI の出力（機器のランプを点ける）は未対応。
- Safari（iPhone・Mac）は Web MIDI に対応していないため使えない（その旨を表示するだけ）。
- 学習の対象は「スタジオ」の操作部と自律演奏の開始ボタンに限る。
