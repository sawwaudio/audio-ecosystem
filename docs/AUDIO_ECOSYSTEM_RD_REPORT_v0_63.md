# saww audio ecosystem R&D レポート v0.63
**2026-11-08（チャット）／無料版で鳴らせる生き物の声を、分類ごとに4種に絞る**

## 0. 前提
- 自動実行の v0.62（自律演奏の楽器を拍に合わせる）と VCSL の楽器一覧（docs/VCSL_INSTRUMENTS.md）のパッチを先に当てた（`git am`）。

## 1. オーナー要望（2026-11-08 10:34）
- 「無料版生き物の声出せすぎだから、各5種類ぐらいまで、まあ各3種類まあ4種類ぐらいに絞って、残りはプロにする」

## 2. 変えたこと
- **無料版の生き物**：分類ごとに4種、計20種にした。97録音のうち、残りの77録音は PRO。
  - 一覧は data/product_tiers.json の `recordings.free` だけで決まる。
  - 選び方：CC0・CC BY（商用モード「BY-SAを除く」でも鳴る）、写真がある・日本の録音を優先。
  - 鳥は、初期設定（v0.58）の4種と同じにした。そのため、無料版でも初期設定のまま鳴る。

| 分類 | 無料版の4種 |
|---|---|
| 鳥 | ウグイス（横浜）・ウタツグミ・ミソサザイ・ナイチンゲール（ロシア） |
| 虫 | アブラゼミ・ヒグラシ・虫の合唱（千葉・柏）・夜のコオロギ（米国ワシントン州） |
| 両生類 | ヨーロッパヒキガエル・水田のカエル（和歌山）・太平洋アマガエルの合唱・マレーシアのカエル |
| 哺乳類 | ノロジカ・オオカミ・フクロテナガザル（ベルギー）・コウモリ（巣箱） |
| 水の生き物 | タイセイヨウマダライルカ・ザトウクジラ・イルカ（メキシコ）・庭の池の水中マイク |

- **無料版でも全部鳴るもの**：環境音（川・雨・波・風など）と、自分で読み込んだ音。
- **画面**
  - PRO の生き物のタイルに「PRO」の印（金色）。
  - 無料版では、PRO のタイルを暗くする。タップすると「この生き物は PRO で鳴らせます（無料版は分類ごとに4種まで）」と出す。
  - 無料版では、無料の生き物を先に並べる。
  - タイルの上に、いまの状態を1行で出す（テスト公開中／無料版）。
- **自律演奏・試聴**
  - 本体の候補選び（candidatePool）・playSpecies・previewSpecies が `window.__recAllowed` を見る。
  - PRO の生き物を参加にしていても、無料版では鳴らない。
  - 無料版に切り替えた時は、鳴っている PRO の声を止める。
- **プランの比較表**に2行を足した。
  - 無料：「生き物の声：分類ごとに4種（計20種）。環境音はすべて」
  - PRO：「すべての生き物の声（97録音）」
- **いまの状態**：課金は無効（テスト公開中）なので、全部鳴る。「無料版の見え方を試す」で、無料版の動きを確かめられる。
- 組み込み：build/integrate_v063.py（中で v0.61 → v0.59 → …）。版表記 v0.63。
